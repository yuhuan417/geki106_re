# 页4 武器与捕获整链：逐地址定案（2026-11-12，闭合 ANALYSIS §15.3）

> 本文闭合 §15.3"武器与捕获整链"：自机/挂舱/控制器的生成链、射击、锁定捕获弹、
> 捕获回调与伤害、狙弹链。全部结论出自 `geki106.exe` 反汇编（`re_dis.py` + 字节级复核）。

## 1. 生成链：谁创建武器实体

### 1.1 三个生成源（全部入演员队列 `0x4AD40C`，原语 `0x448FF0`，实体 0x48 字节，ctor `0x445C00`）

| 源 | payload {x, y, type, param} | 时机 |
|---|---|---|
| 脚本 op01 | `(320\|370, 240, 1, 0)` | 每关开场（32 个脚本中 op01 全部为 type 1） |
| 死亡重生 `0x460C00`（`0x460D08..0x460D1F`） | `(player.x, player.y, 1, 1)` | 命数>0 时；param=1 → timer=-1 闪烁入场 |
| **武器套件生成 `0x446540`** | 见下 | 自机 spawn 状态机 timer==-1（重生）与 t==120（开场 2 秒后）各一次 |

`0x446540`（由 `0x4023EC` 从自机 spawn 状态机 `0x446600` 的 timer==-1 / t==120 分支调用）连发三体：

```
payload = {0, 0, 0x1000001, player}      → spawn#1：挂舱本体（type 0x1000001）
payload[1] = 5（写 [esp+0x18]@0x446597） → spawn#2：type 5（锁定弹控制器）
payload[1] = 8（写 [esp+0x18]@0x4465AE） → spawn#3：type 8（伴随控制器）
三次 param 均为旧自机指针；[player+0x24] = spawn#1 句柄
```

### 1.2 演员 ctor `0x445C00` 的分派（`0x445CA7`/`0x445CBE` 两级）

```
type & 0xFF000000 == 0x01000000 → 0x401AF0 → 0x42C4D0（挂舱 ctor，§2）
type == 1  → 0x445ECE（自机本体：8 变体行为表 = (操作器?4:0)+选机，§4）
type == 5  → 0x445E47（锁定弹控制器：8 变体，§3）
type == 6  → 0x445CE7（行为 0x447640 —— §6 死码）
type == 8  → 0x44601E（行为 0x4015FF→0x447410；[+0x1C]=param、[+0x20]=[+0x24]=5）
type == 9  → 0x446227（行为 0x40116D→0x447F90：每帧按存活位 boolset 0x56CCB8 bit4）
type == 10 → 0x446117 →（行为 0x401E06）
type == 0x0B000001（头像自机）→ 0x446059（行为 0x401E06→0x448C70）
```

## 2. 挂舱 ctor `0x42C4D0`（0x01 族，type 低字节 = 型号）

- `[ent+0x20]` = payload[3]（**所有者 = 自机**）；`[ent+0x18]`=1（使能位）；`[ent+0x1C]`=0（冷却）。
- 12 项行为表（栈上 12 个 thunk），按 `(type-0x1000001)` 分 3 型、每型按**选机编码** `0x45AFC0(0x4AB5B0,0xC000)` 取 4 变体：

| 型 | 变体 0..3 |
|---|---|
| 0x1000001 | `0x42C810` `0x42CC50` `0x42D070` `0x42D370` |
| 0x1000002 | `0x42C8F0` `0x42CD70` `0x42D150` `0x42D4A0` |
| 0x1000003 | `0x42CA70` `0x42CEF0` `0x42D260` `0x42D6A0` |

### 2.1 变体 `0x42C810`（撃/选机0）的共通结构

```
[ent+0x1C]++（冷却）
if (btn0 按住 [0x4AB594] && 冷却 > 5):          ; 每 6 帧一发
    生成 0x120B1121 于 (owner.x+0x10, owner.y)、param=0xE00 入 0x4AD46C
    0x42C600(this)（伴随弹，§2.2）
    [ent+0x1C] = 0
    音效槽 0，声像 (owner.x-320)*16（0x450350）
if (owner 存活 [+0x34] 且 [ent+0x18]!=0) 返回 1；否则返回 0（随自机消亡）
```

### 2.2 `0x42C600`（伴随追踪弹）

- 门：`[player+0x2C] >= 0 → 直接返回`。`[player+0x2C]` 由自机 spawn 状态机每帧 +1
  （`0x446681..0x44668A`，字节级 `42`=inc），**随附代码恒 ≥0 → 伴随弹体不可达**
  （负值写点未发现；保留机制记录，表现以实测为准）。
- 主体（门开时）：`0x43BCE0`（thunk `0x4021EE`，类型过滤 0x0F3460CBA）找最近敌机 →
  8.8 速度打包 `(vy<<16)|vx` → 左右两发 **0x12061124** 于 `(player.x±0xC, player.y∓0xC)`。

## 3. 锁定弹控制器（type 5）

8 变体（(操作器?4:0)+选机）：`0x446C50 0x446D30 0x446E20 0x446F10 0x447000 0x447110 0x447200 0x447320`。
变体 `0x447000`（操作器+选机0）的结构：

```
if (btn1 按下沿 [0x4AB597]):
    生成 0x10008041（捕获光束）于自机位置入 0x4AD46C
    0x446470(player,1,1)（锁定输入切换）
    0x45F530(0x4CD4A0, 0)（结算计数钩子）
    [ctl+0x20] = 1（光束存续闩锁）
if ([ctl+0x20] != 0):
    if (btn1 松开沿 [0x4AB599] 或自机已亡 [+0x34]==0):
        0x446470(player,0,1)
        if ([0x56CCA0]!=0 且 [0x56CC9C]==0):      ; 命中统计门
            if ([player+0x30] < 0x1E): [player+0x30] = 0x1E   ; 30 帧窗口
        byte[0x56CC94] = 1
        [ctl+0x20] = 0
返回自机存活
```

`[player+0x30]`=30 由自机状态机逐帧递减（`0x44668F`），按 bit1 交替 `[[ent+0x38]+4]` 的
源矩形（0x30/0）——**捕获成功后 30 帧的自机精灵闪烁**。

## 4. 自机本体（type 1）行为：8 变体

`0x4466F0 0x4467D0 0x446890 0x446950 0x446A10 0x446AD0 0x446B50 0x446BD0`
（= 4 机 × 鼠标/操作器；`0x446890`/`0x446950` 逐字节同式）。共通结构（变体 `0x4466F0`）：

1. `0x446600` spawn 状态机：`[+0x20]`++（timer）、`[+0x2C]`++、`[+0x30]` 递减+闪烁；
   timer==-1 → `0x446540` 生成武器套件 + `[+0x10]`=1、timer=0x12D(301)；
   timer==40 且命数 0 → 返回 0（游戏结束）；timer==120 → 再生成套件 + `[+0x10]`=1；
   timer==300 → 节点可见。
2. **btn1 按住且非松开沿 → 调 `0x446470(this,0,1)`（锁定输入切换），跳过移动**
   （"锁定按住冻结"）；否则跟随指针：`(d>=0 ? d+3 : d)>>2`（`0x446726..0x446741`）。
3. 坐标写入自机镜像 `[0x56CC8C]/[0x56CC90]`（0x45A690 打包）；显示矩形 `(x-24,y-24)`；
   返回 `[+0x18]!=0`。

`0x446470`（锁定输入切换，ret 8）：

```
preset = 7 + (操作器?8:0) + 选机*2 + (a!=0)         ; ∈ 7..22（§10.2 公式实证）
dl = ([ent+0x1C] & 1)
a!=0 → 0x44E620(输入, preset, x, y, dl)（载锁定预设+基点）
a==0 → 0x44E470(输入, preset, dl)（仅基点）
[ent+0x1C] = a!=0 ? ([ent+0x1C]|2) : ([ent+0x1C]&1)   ; bit1 = 锁定标记
```

## 5. 捕获光束 0x10008041（ctor `0x42DABC`）

- 8 变体行为（(操作器?4:0)+选机）：`0x42E460 0x42E520 0x42E660 0x42E810 0x42EA70 0x42EB30 0x42EC70 0x42EE20`；
  **type != 0x10008041（如 0x10008043）→ 固定行为 `0x4021A3`→`0x42F080`**。
- 字段：`[+0xC]`=0x30（半径 48）、`[+0x10]`=1、`[+0x18]`=-1（HP 无限）、
  `[+0x24]`=选机、`[+0x28]`=param、源矩形 `(0x8D,0x2D,0x93,0x32)`（6×5 帧条）、显示 `(x-3,y-3)`。
- **选机==3 特例**：type 0x10008043 → `[+0xC]`=0x10000（半径 65536 = 全屏）、`[+0x10]`=0、
  矩形 `(0x60,0x60,0xBF,0xBF)` —— 四号机全屏即时捕获。
- `0x42F4B0(beam, arg)`：帧条步进（0x45A790 每帧 ±3px 源矩形 + 显示位移），arg=0 增至 l==0x90、
  arg=1 减至 l==0x60 时返回 1 —— 即"蓄力/收缩"的帧动画。
- 玩家弹族总派发 `0x42D780`（ctor thunk `0x401DCA`，队列原语 `0x430290`，0x48 字节）：
  `0x11 族 → 0x42A820`、`0x12 族 → 0x42B210`、`0x10008041 → 0x42DABC`、
  `0x10032215 → 0x42DC4C`、`0x10000012 → 0x42D903`、`0x10000051 → 0x42D8B4`、
  `0x10000052 → 0x42D836`。
- 0x12 族子弹 ctor `0x42B210`：`[+0x1C]=8.8 vx`、`[+0x20]=8.8 vy`（payload[3] 低/高 16 位）、
  `[+0x24]=x<<8`、`[+0x28]=y<<8`、`[+0x18]=1`；按精确型再分（0x120A112F/0x12061128/0x12041129/
  0x12061124/0x12061127/>0x120A112F …）。

## 6. 捕获/伤害回调 `0x43C6C4`（组 2 命中处理 `0x43C460` 的主体跳转）

组 2（自机弹×敌机）命中 → `0x401136`→`0x43C460(ctx, bullet, enemy)`：

1. 命中火花 **0x41000004**：偏移按 `bullet.type & 0x7000` 分流（0x1000=弹速>>7、
   0x2000=随机 ±15、其它默认）入 0x4AD4CC。
2. **`value = 0x43AE60(enemy)`**（thunk `0x40123A`）：
   - `frame > [enemy+0x54]`（锁定已过期）→ 非 0x2X 族返回 `(frame+63)/64 - [enemy+0x48]`、
     0x2X 族（type&0xF0000000）返回 `1 - [enemy+0x48]`；
   - `frame <= [+0x54]`（锁定未过期）→ **返回 0**。
3. `value != 0` → 锁定效果路径：首次（`[enemy+0x4C]==0` → 置 1）生成 **0x41000006**（锁定圈）
   与 **0x41000005**（param 4，旋转框）；`[enemy+0x48]++`（锁定计数）、
   **`[enemy+0x54] = word[0x56CCA8] + 0x10`（期限 = 当前帧 + 16）**；统计
   `[0x56CC98]/[0x56CCA0]` 写入；音效槽 6 声像 `(enemy.x-320)*16`；
   **选机==3 → 跳过锁定相位直接伤害**（`0x43C84F jne 0x43C9C2`）；
   弹自标记 `[bullet+0x10]=0`、`[bullet+0x1C]=4`（离场态）。
4. `value == 0` → `0x43C9C2` 伤害路径：
   - `damage = (bullet.type >> 16) & 0xFF`（由调用者从 `bullet.type` 字节 2 取——
     **伤害编码在型值的第 3 字节**：0x120B1121→11、0x12061124→6、0x10008041→0x80(128)、
     纯锁定弹该字节为 0 → 无伤害）；
   - 弹 HP `[bullet+0x18]`：非 0/-1 则递减，归零 → `[bullet+0x10]=0`（穿透计数）；
   - `damage >= [enemy+0x18](HP)` → 击破分支：**6 型免普通爆块名单**
     `0x24000011 0x2300000E 0x27000011 0x29000013 0x2C00000B 0x2C00000A` 跳过爆炸块
     （与 §5.2 名单一致），普通敌生成 `0x61000004` 演出入 0x4AD52C。

**锁定三字段**（敌机 ctor 公共初始化 `0x43A83A` 清零）：`[+0x48]`=锁定计数、
`[+0x4C]`=首锁标记、`[+0x54]`=期限帧。除捕获回调与 `0x43AE60` 外**无其他读者**
——"捕获"=锁定圈视觉 + 期限管理，无独立捕获击杀（伤害仍走通用路径）。

## 7. 0x8000 弹门与组 2 门

组 2 遍历 `0x43C060`：`0x45B030(0x56CCB8, 2)`（bit1 清）→ 全体参与；
bit1 置（演出/过场）→ 仅 `bullet.type & 0x8000` 的弹继续（`0x43C085..0x43C08B`）。

## 8. 狙弹链（头像自机，补完既有结论）

- 头像自机 `0x0B000001`（行为 `0x448C70`）held 攻击且 `0x56CCC0` 无 `0x10` → 生成一枚
  `0x1B000001` 并**置位 `0x56CCC0` bit4（`0x448DFE`）**（占用）。
- 狙弹行为 `0x430080`：每帧 x+=7；x>480 裁右缘；x≥512 或 HP 0 → 死亡并
  `0x45AF60(0x56CCC0, 0x10)` 清占用（`0x4300EC`）。
- 命中分支 `0x43C95A`：目标 HP 无条件减 1、自身 HP 置 0，不走共用结算尾。

## 9. 死码与残留（对 §15.2 的最终口径）

1. 演员 type 5/8/9/10 的**小整数型**生成点：随附 32 脚本的 op01 只有 type 1；
   type 5/8 由 `0x446540` 代码生成（**活**）。**type 6 不是死码**：捕获束命中
   `0x43C55D` 会生成 type6（ctor `0x445CE7`），其行为 `0x447640` 的 7 项栈表
   `0x11FFA321×2/0x1180A322/0x1140A323/0x11FFA324/0x1140A325/0x11C0A326`
   （索引 `([ent+0x28]>>8)&0xF`）在 `sub[0x28]==0` 时整轮爆发 30 发，
   **爆发后返回 0 自灭**（0x4477FB `xor al,al`）—— 旧"零生成点/死码"结论作废。
2. `0x42C600` 伴随追踪弹：门 `[player+0x2C] < 0` 在随附代码下恒假（该计数器只增），
   主体不可达；机制如 §2.2 记录。
3. `0x447640` 收尾 `0x4477E9` 置 `0x56CCB8` bit12（`0x45AF30(…,0x1000)`），
   然后自灭；bit12 的读者未发现，保留为机制记录。

## 10. 0x11 族（捕获僚机武器弹）与捕获键（2026-11-18 落地）

`0x42D780` 的 `0x11` 分支 → ctor `0x42A820`（不是 `0x42B210` 的 0x12 族）：

```
[+0xC]=8、byte[+0x10]=0、[+0x1C]=rec[3]&0xFF、
[+0x20]=(rec[3]&0x1000)?-1:-0x3D、[+0x24]=x<<8、[+0x28]=y<<8、
[+0x2C]=rec[3]&0x1000、[+0x18]=1；节点层0/rect(0,0,1,1)/active=0
```

六型行为（`0x42AAA0/AB90/ACF0/AE70/AF90/B120`）共用 `0x42A9D0`：
相位++、在当前位置生成 `0x4100000B`；**相位 < 0** 时按 `(param+phase)*60`
做 sin/cos 各 +12 的 8.8 螺旋；相位 ≥ 0 交给各型运动段。要点：

- `0x42AAA0` 螺旋扩散：x=初值+sin((ph+2·param)·30)·ph/43（0x2FA0BE83+`sar 3`），
  ph>8 开碰撞、ph≥0x64 离屏自灭。
- `0x42AB90` 四边反弹：初速 `(cos,sin)(param·60)·12`，ph<0x96 撞边反向 + SE 0xF。
- `0x42ACF0` 扇形发射器：**HP==0 且 [+0x2C]==0** 时按 0x1100..0x1138（步4）
  生成 15 发同型（子弹出生的 0x1000 位阻止递归）。
- `0x42AE70` 横移下坠、`0x42AF90` 追踪最近敌机（0x43BCE0/0x45AA80/0x45A9A0）、
  `0x42B120` 横向漂移。

**捕获键**：输入记录 `0x4AB594..599` 只有 b0/b1/e0/e1/r0/r1；`0x447410` 读
**e0/e1**（`0x4AB596/597`）。手册的"双键同按（或映射键）"在复刻侧落为：
按 X ⇒ 同帧 b0=b1=1 ⇒ e0=e1=1，type8 捕获控制器开火；普通武器槽同帧也看到
b0/b1（与双键同按一致）。没有独立的第三按钮字节。

⚠ 实机路径还依赖 `0x45135F` 的外层门：只有 `byte[0x56CCB5]`（回放标志）非 0
才调 `0x45D2B0`。复刻侧 `replay_play` 曾每帧无条件跑，非回放页也用刚录的
上一帧覆盖 `inp.rec` 的 b0/b1/e0/e1 ⇒ X 的按下沿被冲掉、捕获束不出。已按
0x45135F 加门（2026-11-18）。

## 11. 0x6E 族（捕获僚机武器控制器）与 0x100D1211（2026-11-19 落地）
