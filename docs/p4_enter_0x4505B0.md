# 页 4 / 页 11 阶段进场函数精确定案：`0x4505B0`（`0x4505B0`–`0x450DCA`）

## 0. 总述

`0x4505B0` 是页 4（游戏本体）/页 11（回放播放）共用的阶段进场（每阶段一次）：先按 `[App+0x2BC]==0xB`
决定"从回放管理器 `0x4CD5D8` 恢复 `0x2C`(44) 字节阶段头"还是"按关数 `[0x4AB5C8]`／周目 `[0x4AB5CA]`
三分支查栈内常量表生成同一头部"（另有 `0x4AB5B0` 位 0 = 鍛錬 的固定参数旁路）。头部经 `0x401EB0→0x45D160`
写入 `0x4CD5D8` 并打 `"GRPD"`/`"106A"` 戳；再用头部 4 字节回写 `0x4AB5B0` 位域、4 个字段作 `0x458D60`
实参做场景重置；随后清统计区、载调色板、重置输入、预载 21 个脚本槽、初始化流程 VM、起帧门，
返回值 = `0x4AB5C0` 离页旗标是否为空。

> 约定：本文数值默认十六进制，需要时在括号内给十进制。只写规格，不含实现代码。
> `0x4505B0` 的全部行号/地址均以 `geki106.exe` 内存映射镜像（ImageBase `0x400000`）为基准。

## 0.1 前置：栈帧、块基址 `B`、以及"push 造成的位移陷阱"

| 步骤 | 地址 | 动作 | `esp` |
|---|---|---|---|
| 入场 | — | 返回地址在 `[S]`（`S` = 入场时 `esp`） | `S` |
| 局部 | `0x4505B0` | `sub esp,0xD8` | `S-0xD8` |
| 保存 | `0x4505B6` | `push ebx` | `S-0xDC` |
| 保存 | `0x4505B7` | `push esi` | `S-0xE0` |
| 保存 | `0x4505EA` | `push ebp` | `S-0xE4` |
| 保存 | `0x4505F2` | `push edi` | `S-0xE8` |
| 保存 `this` | `0x4505C1` | `mov [esp+0xDC],esi`（`esp=S-0xE0` ⇒ `S-0x04` = `B+0xD4`） | — |
| 块基址 | `0x4505F5` | `lea edi,[esp+0x10]`（`esp=S-0xE8`）⇒ **`B = S-0xD8`** | — |

由此得到两条换算规则（**这是本文所有偏移的唯一来源**）：

1. `esp = S-0xE8` 时（`ebp`/`edi` 已压、无待用实参）：`块偏移 = disp - 0x10`。
2. 若某条 `mov` 执行时**已经压入了下一次调用的实参**（`esp = S-0xEC`）：`块偏移 = disp - 0x14`。
   本函数有 5 条这样的存储，全部落在 `0x450611`/`0x450621`/`0x450634`/`0x450644`/`0x450657`：

| 地址 | 指令 | 当时 `esp` | 实际块偏移 | 值 |
|---|---|---|---|---|
| `0x450611` | `mov byte[esp+0x2F],al` | `S-0xEC`（`0x45060A push 1` 已执行） | `+0x1B` | `0x45AFF0(0x4AB5B0,0x200)` |
| `0x450621` | `mov byte[esp+0x30],al` | `S-0xEC`（`0x45061A push 2`） | `+0x1C` | `0x45AFF0(0x4AB5B0,1)` |
| `0x450634` | `mov byte[esp+0x31],al` | `S-0xEC`（`0x45062A push 0xC000`） | `+0x1D` | `0x45AFF0(0x4AB5B0,2)` |
| `0x450644` | `mov byte[esp+0x2C],al` | `S-0xEC`（`0x45063D push 1`） | `+0x18` | `0x45AFC0(0x4AB5B0,0xC000)` |
| `0x450657` | `mov word[esp+0x24],bx` | `S-0xEC`（`0x450651 push ebx`） | `+0x10` | `0` |

另：`0x4505BA xor ebx,ebx` 之后 **`ebx` 全程为 `0` 且再未被赋值**（只有 `push ebx`/`bx`/`bl` 的读用），
故下文所有"`push ebx`"= 压 `0`，所有 `mov [...],bx`/`mov [...],bl` = 写 `0`。

块大小：最后一个字写入点 `0x450821 mov word[esp+0xE2],0x7D0` ⇒ `B+0xD2`，占 `+0xD2..+0xD3`
⇒ **块 = `B+0x00`..`B+0xD3`，共 `0xD4`(212) 字节**；`B+0xD4` 另存 `this`（见上表 `0x4505C1`）。

## 1. 进场开头分支：`[App+0x2BC] == 0xB`（页 4 vs 页 11）

### 1.1 地址链（为什么 `0x2BC` 是页号、`0xB` 是回放播放页）

| 地址 | 证据 | 结论 |
|---|---|---|
| `0x459363` | `eax=[esi+0x2BC]`，页机 `0x459360` 用它分页 | `App+0x2BC` = **页号** |
| `0x4593A1..0x4593B3` | `页号-1` → 字节表 `0x459618` → `jmp [0x4595E4+cl*4]` | 页号 → handler |
| `0x459618` + `0x4595E4` | 表项第 4 项（下标 3）= `0x4593C2`；页 4 与页 11 都得下标 3 | **页 4 = 页 11 = `0x4593C2`** |
| `0x4593C2` | `call 0x401050`→`0x4505B0` 之后 `call 0x40184D`→`0x451110`（while）、`call 0x401807`→`0x451C50` | 本函数为页 4/11 的**进场** |
| `0x4505C8` | `cmp dword[esi+0x2BC],0xB`（`0xB` 先由 `0x4505BC mov ecx,0xB` 装入） | 分支判定 |
| `0x450AFA` | `byte[0x56CCB5] = ([esi+0x2BC]==0xB)` | 全局"回放播放中"旗标 |
| `0x45FA6E` | `0x56CCB5` 被回放记录流当"正在播放"判据 | 页 11 = 回放播放页 |

### 1.2 两条路径的差异

| 项 | 正常分支（页 4，`0x4505CE jne` 落到 `0x4505E4`） | 回放分支（页 11，`0x4505CE` 不跳） |
|---|---|---|
| 阶段头来源 | 由 `si`/`bp` 现算 + 常量表 | 从回放管理器 `0x4CD5D8` 复制 |
| 复制指令 | `0x450A25 lea eax,[esp+0x10]`（= `B`）→ `0x450A2F call 0x401EB0` | `0x4505D0 lea eax,[esp+8]`（`esp=S-0xE0` ⇒ `B`）→ `0x4505DA call 0x401EEC` |
| 被调函数 | `0x401EB0` = `0x45D160`：`rep movsd` 11 dword 从块写进 `[ecx+4]`，再写魔数 `0x44505247`("GRPD")@`[obj+4]`、`0x41363031`("106A")@`[obj+8]`，`ret 4` | `0x401EEC` = `0x45D1A0`：`rep movsd` 11 dword 从 `[ecx+4]` 读进块，`ret 4` |
| 头部 `+0x2C..+0xD3`（常量表区） | 被填满（分支 A）/ 保持 0（分支 B）/ 部分填（分支 C） | 完全不被填（直接跳过） |
| 后续 | 落到 `0x450A25` 继续 | `0x4505DF jmp 0x450A3D`：**跳过 `0x450A25..0x450A3B` 全部参数计算与写回** |
| 净效应 | 算出的头写入 `0x4CD5D8`（覆盖旧记录） | `0x4CD5D8` **不被改写**，本次运行沿用录像里的头 |

⇒ 回放分支把"录像里记下的阶段配置"原样灌进同一个栈块，因此下游（`0x450A3D` 起的状态字回写、
`0x458D60` 的 4 个实参、`0x56CCB0` 的等级值）全部按录像值执行 —— 这就是"回放能复现同一关配置"的机制。

`[esi+0x2BC]` 在本函数的唯一用途：`0x4505C8`（取头）与 `0x450AED..0x450AFA`（写 `0x56CCB5`）。

## 2. `0xD4`(212) 字节参数块：三分支完整字段表

### 2.0 与其他分支无关的共用字段（`0x4505F9`–`0x450644`，写在三分支之前）

| 块偏移 | 尺寸 | 含义 | 来源 / 写入地址 |
|---|---|---|---|
| `+0x00` | dword | 魔数槽（本函数留 `0`；被 `0x45D160` 覆写为 `"GRPD"`=`0x44505247`） | `0x4505F9 rep stosd`（`ecx=0xB` 由 `0x4505BC` 装入）；覆写在 `0x45D16D` |
| `+0x04` | dword | 版本槽（留 `0`；覆写 `"106A"`=`0x41363031`） | 同上；覆写在 `0x45D178` |
| `+0x08` | dword | 恒 `0`（全函数无写点，只有 `rep stosd`） | `0x4505F9` |
| `+0x0C` | dword | 恒 `0`（同上） | `0x4505F9` |
| `+0x18` | byte | `0x4AB5B0` 位段 `0xC000`（bits14..15）的现值，`0..3` | `0x45062A push 0xC000` / `0x450638 call` → `0x450644` |
| `+0x1B` | byte | `(0x4AB5B0 & 0x200)!=0`（位 9） | `0x4505FB push 0x200` / `0x450605 call` → `0x450611` |
| `+0x1C` | byte | `(0x4AB5B0 & 1)!=0`（位 0 = 鍛錬） | `0x45060A` / `0x450615` → `0x450621` |
| `+0x1D` | byte | `(0x4AB5B0 & 2)!=0`（位 1 = 操作器） | `0x45061A` / `0x450625` → `0x450634` |
| `+0x1E` | byte | 恒 `0`（无写点、无读者） | `0x4505F9` |
| `+0x1F`..`+0x2B` | 13B | 恒 `0` | `0x4505F9` |

两个位域 helper 的精确语义（**注意 mask=0 时两者不同**）：

| helper | 地址 | `mask != 0` | `mask == 0` |
|---|---|---|---|
| 取值 | `0x45AFC0`（thunk `0x4019C9`，`ret 4`） | `(flags & mask) >> (mask 最低置位的位数)` | **恒返回 `0`**（`0x45AFC7 and eax,ecx` → `0x45AFC9 je 0x45AFD9` 直接 `ret`） |
| 测试 | `0x45AFF0`（thunk `0x40208B`，`ret 4`） | `(flags & mask) != 0 ? 1 : 0` | **`flags == 0 ? 1 : 0`**（`0x45AFF6 je 0x45B006` → `0x45B00D sete al`）——即"是否全清空" |

`0x45B0A0`（thunk `0x40114A`，`ret 8`）= `0x45B0A0(obj,mask,value)`：只看 `value` 的**低字节**
（`0x45B0A0 mov al,[esp+8]; test al,al`），非 0 → `flags |= mask`（`0x45B0AF`），0 → `flags &= ~mask`（`0x45B0C0`）。
`0x45B0E0`（thunk `0x401636`，`ret 8`）= 把 `value` 写进 `mask` 指定的位段（按 mask 最低置位定位并同步左移）。

### 2.1 `si`/`bp` 的来源与三条分支的判定（`0x4505E4`–`0x450694`）

| 符号 | 定义地址 | 含义 |
|---|---|---|
| `esi`/`si` | `0x4505E4 mov esi,dword[0x4AB5C8]` | 关数（低 16 位；高 16 位 = 周目，见下） |
| `bp` | `0x4505EB mov bp,word[0x4AB5CA]` | 周目（`0x4AB5CA` = `0x4AB5C8+2`，即同一 dword 的高 16 位） |
| 旁路判定 | `0x450648 call 0x40145B`（=`0x45B030(mask=1)`：位 0 **清**时返回 1）；`0x45064F je 0x450686` | `al==0` ⇒ `0x4AB5B0` **位 0（鍛錬）为 1** ⇒ 走固定参数旁路 |
| 分支 C | `0x450686 cmp si,8` / `0x45068A jge 0x45096E` | `si >= 8`(8) |
| 分支 B | `0x450690 cmp bp,3` / `0x450694 jg 0x450943` | `si < 8` 且 `bp > 3`(3) |
| 分支 A | 顺序落到 `0x45069A` | `si < 8` 且 `bp <= 3` |

旁路（`0x450651`–`0x450681`，位 0 = 鍛錬 为 1 时）也写同一批字段，必须一并复刻：

| 块偏移 | 值 | 地址 |
|---|---|---|
| `+0x10` | `0` | `0x450657`（`esp=S-0xEC`） |
| `+0x12` | `0` | `0x45066C` |
| `+0x14` | `0` | `0x450673` |
| `+0x16` | `0` | `0x45067C` |
| `+0x19` | `0x64`(100) | `0x450678` |
| `+0x1A` | `6`(6) | `0x450665` |

旁路里 `0x450661 neg eax / 0x450663 sbb al,al / 0x45066A and al,0x9F / 0x450671 add al,0x64`
是"`cond ? 3 : 0x64`"的编译残留，其输入 `eax` 来自 `0x45065C call 0x4019C9`
= `0x45AFC0(0x4AB5B0, 0)`（`0x450651 push ebx` 推的是 `0`）——**mask=0 恒返回 0**，
故 `al` 恒为 `0x64`(100)（若 `eax!=0` 则得 `3`）。复刻时按常量 `0x64` 处理。

## 4. 状态字回写：`0x450A3D`–`0x450A83`

此处 `esp = S-0xE0`（正常分支：`0x450A34 mov esi,[esp+0xE4]` 后 `0x450A3B pop edi`、`0x450A3C pop ebp`；
回放分支：只有 `ebx`/`esi` 两个 push，`0x4505DF` 直接跳到这里）⇒ **`B = [esp+8]`，块偏移 = `disp-8`**。

| 地址 | 读 | 调用 | 目标位域 | 语义 |
|---|---|---|---|---|
| `0x450A3D` | `mov ecx,[esp+0x24]` ⇒ `B+0x1C` | `0x450A41 push ecx` + `0x450A42 push 1` → `0x450A49 call 0x40114A`(=`0x45B0A0`) | `0x4AB5B0` 位 0 | `位0 = byte[B+0x1C]`（鍛錬） |
| `0x450A4E` | `mov edx,[esp+0x25]` ⇒ `B+0x1D` | `0x450A57 push edx` + `0x450A58 push 2` → `0x450A5A call 0x40114A` | 位 1 | `位1 = byte[B+0x1D]`（操作器） |
| `0x450A5F` | `movsx eax,byte[esp+0x20]` ⇒ `B+0x18`（有符号扩展） | `0x450A64 push eax` + `0x450A65 push 0xC000` → `0x450A6F call 0x401636`(=`0x45B0E0`) | 位段 `0xC000`（14..15） | `= B+0x18`（0..3） |
| `0x450A74` | `mov ecx,[esp+0x23]` ⇒ `B+0x1B` | `0x450A78 push ecx` + `0x450A79 push 0x200` → `0x450A83 call 0x40114A` | 位 9 | `位9 = byte[B+0x1B]` |

要点：

- `0x45B0A0(obj,mask,value)` 只取第 3 实参的**低字节**（函数内 `mov al,[esp+8]; test al,al`），
  所以 `mov ecx,[esp+0x24]` 这种**未对齐 dword 读**读到的正是 `B+0x1C` 那一字节 + 后续字节；
  值仍是 0/1，行为等价于 `byte[B+0x1C]`。
- `0x45B0E0(obj,mask,value)` 用 mask 的最低位定位并左移同步，`0xC000` ⇒ bits14..15。
- 正常分支这四个值本来就是从 `0x4AB5B0` 读出来再写回 ⇒ **恒等回写（no-op）**；
  回放分支则把录像里的值**覆盖**到 `0x4AB5B0`（这就是"回放不改变玩家配置"的实现方式）。

## 9. 复刻要点清单（按执行顺序，全部有地址支撑）

1. `0x4505C8`：读页号，`==0xB` 走回放头恢复（`0x401EEC`），否则现算。
2. 现算时先判 `0x4AB5B0` 位 0（`0x450648`）：为 1 ⇒ 固定参数（`0x450651..0x450681`），
   否则按 `si`/`bp`（`0x4505E4`/`0x4505EB`）分 A/B/C（`0x450686`/`0x450690`）。
3. 头部 4 字节一律来自 `0x4AB5B0`（`0x450611..0x450644`），正常分支是恒等回写。
4. `0x450A25` 只把 `0x2C` 字节交给 `0x45D160`（`+0x2C..+0xD3` 是内部查表区）。
5. `0x458D60` 只收 4 个标量，落点是 `0x4CD4A0+0x2C/+0x30` 与 `0x4CD590+0x30/+0x3C`。
6. `0x56CCB0` = 等级初值（头部 `+0x12`）。
7. 21 个脚本槽预载按 §7 顺序；任一失败 `0x4AB5C0 |= 8` 但不中止。
8. 返回 `(0x4AB5C0==0)`。
