# 页4 关卡间跳转与 VM 冻结门：逐地址定案（2026-11-12）

> 本文回答两个问题：**战斗中脚本 VM 如何被暂停/恢复**（关卡内部与关卡之间的衔接），
> 以及**一局游戏从菜单到结局的完整跳转链**。所有结论均来自 `geki106.exe` 反汇编，
> 方法与 `p4_vm_0x460350.md` 相同（`re_dis.py` + 原始字节扫描）。
> 十六进制后括注十进制。

---

## 1. 核心机制：`0x56CC84` = 流程 VM 的本地冻结门

### 1.1 门的位置与判定

- VM 单例 `0x56CC4C` 的对象布局中 `+0x38` 是旗标子对象 —— 其地址就是 **`0x56CC84`**，
  旗标 dword 在 **`0x56CC88`**（BSS 初值 0，无 ctor 初始化点）。
- `0x460350` 每次取记录前（`0x460376`）执行 `0x45B030(0x56CC84, 0)`：
  mask=0 时该函数返回 **`flags != 0`**；非 0 → `0x46037F jne 0x46069F` 直接 `return 0`
  —— **只要任一冻结位置位，VM 时钟（`+0x04`）停走，游标不动，记录不执行**。
  已到点但被冻结挡住的记录在解冻后照常执行（时间戳判定是 `<=`）。

### 1.2 七个冻结位的置位/清位全表

全部经旗标 API（`0x45AF30` 置 / `0x45AF60` 清 / `0x45AF10` 赋 0）操作 `0x56CC88`：

| 位 | 置位点 | 清位点 | 语义 |
|---|---|---|---|
| `0x2` | `0x42729A`（op05 子 ctor `0x61000002`） | 行为 `0x427510`：`0x45AFC0(0x56CCB8,0x8000)==0` 时清位并自灭 | 等待 0x61000001 演出门完成 |
| `0x4` | `0x4230EC`（`0x51000001` 结算计数 ctor case0） | `0x423A95`（结算计数 finish） | 结算计数进行中 |
| `0x8` | `0x449834`（op04 ctor `0x59000003` case，`0x4497E7`） | 行为 `0x44ADC0`：`0x45B030(0x56CCB8,8)!=0`（bit3 清）时清位并自灭 | 演出等待门 |
| `0x10` | `0x42329C`（`0x51000002` 继续总控 ctor case1） | `0x423BA8`（t=35 提前退出）、`0x423D39`（t=180 出口） | 继续总控进行中 |
| `0x20` | `0x43D519`（op05 ctor `0x64000001` case） | `0x441BF4`（二面 boss 控制器 `0x4417D0` 内） | 二面 boss 战斗中 |
| `0x40` | `0x43D67E`（op05 ctor `0x66000002` case） | `0x442683`（庆典编排 `0x441E00` 内） | 通关庆祝演出中 |
| `0x80` | `0x423D45`（继续总控 t=180 出口） | **无独立清位** —— 仅随整字节清零点消失 | 收尾后冻结至离页 |

整字节清零（`0x45AF10(0x56CC84, 0)`）的五个点：

| 地址 | 语境 |
|---|---|
| `0x450D7E` | 页4/11 进场尾部（`0x4505B0`） |
| `0x451086` | `0x450FE0` 链0耗尽 → 装链9 时 |
| `0x453127` | 页8/9/10 共用进场 `0x453050` |
| `0x453D71` | 页14 进场 |
| `0x458E1C` | `0x458D60` 每阶段队列重建 |

其它读点：`0x427605` = `0x45AFF0(0x56CC84, 0x10)` —— `0x61000005` 亮度渐变行为
（`0x427600`）在继续提示期间挂起。

### 1.3 标准关卡内时序（以链0的 Stg1 = 流46 为例，记录实测于 `resource_dec.bin`）

```
t=8520  OP02 (712,240,0x23000015,0)   ← 一面 boss 入场
t=8520  OP05 (0,0,0x61000002,0)       ← VM 冻结门实体（置位 0x2）→ VM 停
        （boss 战斗在实体侧继续跑；0x61000001 演出门持 0x56CCB8 bit15，
          boss 死后 bit15 清 → 0x427510 清 0x2 → VM 恢复）
t=8550  OP04 (0,0,0x51000001,1)       ← 结算计数（置位 0x4）→ VM 又停
        （余量逐帧 -1、每单位 +200 分；btn0 且两计数清零 → finish）
        finish：0x45F710(0x4CD4A0) 阶段结算 + 清 0x4 → VM 恢复
t=8620  OP00 NEXT-STREAM              ← 进入流47（Stg2）
```

流47 开场 `t=0 OP0D param=2`（写关卡号 `0x4CD4A0+0x24`）+ `OP0C`（换 BGM）+ `OP0B`（换 14 层）。
**链0 内关卡间切换不经过任何页出口/菜单** —— 全靠 op00 + 冻结门。

## 2. 链的选择：页4 进场如何决定脚本组

`0x4505B0` 参数块 `B+0x10`（word）= 链索引，`0x450D78 → 0x4602D0(0x56CC4C, 链)`。
来源（`0x4505E4` 起）：

- `si = dword[0x4AB5C8]`（舞台选择器整体）、`bp = word[0x4AB5CA]`（高位 word）。
- `0x4AB5B0` bit0（鍛錬）= 1 → 先走固定参数旁路（`0x450651..0x450681`：命数 6、继续门 0x64），
  **链仍按 si/bp 三分支选**（旁路只改参数块，不改变 B+0x10 的计算路径——旁路块 `+0x10` 写 0
  只发生在鍛錬路径，见下）。

| 分支 | 条件 | 链索引 | 覆盖链 |
|---|---|---|---|
| A（`0x45069A`） | si<8 且 bp≤3 | `si*4 + 0xB` | 11,15,19,…,39 = (45,46,75)…(59,60,75) |
| B（`0x450943`） | si<8 且 bp>3 | `si*4 + 0x38` | 0x38,0x3C,…,0x54 = 二周目副流链 |
| C（`0x45096E`） | si≥8 | 表C `B+0x44+2*bp` | bp0→0x2B(65,75)、bp1→0x2E(45,66..73)、**bp2→0**、bp3→0x58(74) |

**关键定案：页13 确认收尾 `0x4548CF` 写 `dword[0x4AB5C8] = 0x20000`**
→ si=0x20000(≥8)、bp=2 → **分支 C → 链 0 = (45,46,47,48,49,50,51,52) 全周目一贯主链**。
（旧笔记按 si=低字节 0、bp≤3 理解为链 11，是错的：si 的比较用的是完整 dword。）

页12 选关后（`0x4265F4` 写 word[0x4AB5C8]=0..7、`0x4266C8` 写 word[0x4AB5CA]=周目）
→ si<8 → 分支 A/B → 带ClrN过场/二周目副流的分关链。

## 4. 链耗尽分支 `0x450FE0`（极性修正版）

```
r = 0x460350(0x56CC4C)
if (r == 0) return                    ; 流未耗尽（含被冻结门挡住的情况）
al = 0x45B030(0x4AB5B0, 1)            ; = 1 ⟺ bit0(鍛錬) 清 = 普通局
test al,al ; je 0x451091              ; al==0（鍛錬）→ 0x2E/0x58 分支
; ---- 普通局（al!=0）----
id = (s16)0x460800()
id == 0 → 0x451050
id == 9 → 0x451020
其它   → return（链 11..39/0x2B/0x38..0x54 耗尽时不做任何事，
                交由 0x51000002(param=1) 的 0x10000 出口离页）
; 链9（LsBs）耗尽（0x451020）：
0x45F760(0x4CD4A0)                                    ; 离场结算
0x45AF30(0x4AB5C0, 0x45AFF0(0x56CCB8,0x40) ? 0x400000 : 0x200000)
;   bit6 置位（最后 boss 被击破）→ 0x400000 → 页9 → 链0x5C（Edg2=真结局）
;   bit6 清 → 0x200000 → 页8 → 链0x5A（Edg1）
; 链0 耗尽（0x451050）：
if (0x460EE0(0x4CD590) != 0) {        ; +0x40 = 本次页4会话内用过的继续数
    0x45F760(0x4CD4A0)
    0x45AF30(0x4AB5C0, 0x200000)      ; → 页8（Edg1）：用过继续则跳过最终面
} else {
    0x4602D0(0x56CC4C, 9)             ; 装链9（LsBs）
    0x45AF10(0x56CC84, 0)             ; 清冻结门
}
; ---- 鍛錬（al==0，0x451091）----
id == 0x2E → 0x45AF30(0x4AB5C0, 0x400000)   ; 页9
id == 0x58 → 0x45AF30(0x4AB5C0, 0x800000)   ; 页10（ExtrEnding）
```

> `p4_vm_0x460350.md` §4.3 旧伪码把首行写成 `!= 0 → 分支B`，方向反了，本文为准。
> 结构性结论（0x451050=普通局链0/9、0x451091=鍛錬 0x2E/0x58）不变。

`0x4CD590+0x40`（继续数）在每次页4进场由 `0x460930` ctor 清零（`0x460964`），
死亡后继续时由 `0x460E40`（`0x4519F9` 调用）自增 —— 因此"用过继续"只对**当前页4会话**生效。

## 5. 0x51 族：关卡收尾的三个实体

### 5.1 `0x51000001` 结算计数（ctor case0 `0x423027`，行为 `0x423A40`）

- ctor：层13←RT_STRING6（`0x44C640(0xD,6)`，失败走 `0x44CE60(0xD,0)` 再失败 `0x4AB5C0|=2`）；
  `[+0x20] = 0x45F9D0(0x4CD4A0)`、`[+0x24] = 0x45FA00(0x4CD4A0)`（两个阶段千分比）；
  `[+0x30] = param`；**置 VM 门 0x4**；显示节点可见 = (param != 0)。
- 行为：两计数逐帧各 -1 且 `[+0x28]/[+0x2C]` 各 +200；每帧用 `0x423820(this,值,x=0x90/0xF0)`
  盖印数字。btn0 沿时若两计数未清 → 余量一次性换分；两计数皆 0（或 `[+0x30]==0` 直接）→
  `0x45F710(0x4CD4A0)`（0x45F9D0/0x45FA00 比例入结算）+ **清 VM 门 0x4** + 自灭（返回0）。
- 生成源：各 Stg 流尾 OP04（流46 t=8550 param=1、流60 t=560 param=0）。

### 5.2 `0x51000002` 继续总控（ctor case1 `0x42319C`，行为 `0x423B30`）

- ctor：层13←RT_STRING14；`[+0x20] = param(d)`；按 param 选面板源矩形
  （≠0：`(0xA0,0xFF,0xDF,…)`，=0：`(0,0xFF,0x3F,…)`，`0x45A750` 打包入 `[flags+4..]`）；
  **置 VM 门 0x10**；显示节点不可见。
- 行为时间轴（`[+0x1C]` 每帧 +1；字节表 `0x423D84` → 类跳表 `0x423D6C`，类5=空操作）：

| t | 类 | 动作 |
|---|---|---|
| 30 | 0 `0x423B5D` | `0x460EC0()(+0x3C 继续门)!=0` 且 `param==0` → `[0x56CCB4]=1`（开 0x451630 继续提示循环） |
| 35 | 1 `0x423B89` | `lives(0x460EA0)!=0` 且 `param==0` → 清门0x10 + 自灭（提前退场） |
| 50 | 2 `0x423BBA` | 生成 `0x61000007` BGM 音量渐变（步进 -8，目标 0x7F）入 0x4AD52C |
| 120 | 3 `0x423C01` | `0x44CDF0(0x4AA7B0,1,亮,对比,0)` 恢复亮 palette；`[[esi+0x38]+0x1C]=1`；tick 0x4AD40C(`0x448F50`) 与 0x4AD46C(`0x4301F0`) |
| 180 | 4 `0x423C60` | 见下；无 btn0 沿则 `[+0x1C]=0xB3` 驻留等待 |

t=180（btn0 沿后）：

```
选机(0x45AFC0(0x4AB5B0,0xC000))==3      → 0x10000
0x45AFC0(0x56CCB8,0x2000)!=0 (bit13)    → 0x10000
[0x56CCB5]!=0（回放页）                 → 生成 0x51000004
0x45FA30(0x4CD4A0)==0（分数未过参照行：普通=行7、鍛錬=行 stage-1）→ 0x10000
0x460EE0()(+0x40 继续数)!=0             → 0x10000
否则                                    → 生成 0x51000004（结果/排行）
收尾：清门0x10 → 置门0x80 → 自灭
```

- 生成源：**流75 t=30 OP04 param=1**（阶段收尾，链11..39/0x2B/0x38..0x54 专用）；
  **`0x460C00` 死亡处理 lives==0 时 param=0**（`0x460D45`，payload `(x,0,0x51000002,0)`）。
- 语义：param=1 → "关卡收尾"：t=180 等 btn0 →（通常）结果画面 → 0x10000 离页。
  param=0 → "游戏结束"：t=30 开继续提示；继续（0x451630 内 btn0+自机x<320 →
  `0x460E40`(lives=6、+0x3C--、+0x40++、+0x44++) + `0x45F5C0`(重置成绩对象并按当前关卡号
  重设 0x45EF10、`[+0x38]=1`）→ t=180 时 +0x40≠0 → **0x10000 弃关离页**
  （普通局→页3、鍛錬→页12，本页4会话作废；链0 会话的 +0x40 记录使链0耗尽时直通 Edg1）。

## 6. 结局选择与最后 boss

- **`0x2A000001`（8面/最终 boss）行为 `0x40A930`**（ctor 0x2A 族跳表 `0x40A7F8` case0，
  行为 thunk `0x4018C5`）。死亡序列（`[+0x18]` 倒计时 ≤ `0x9C40`(40000)，`0x40AE3D`）：
  生成 `0x4A000006` 爆炸链、`0x61000003` 入 0x4AD4CC、**`0x45AF30(0x56CCB8, 0x40)`（bit6 置位，
  `0x40AE88`）**、`0x45EEA0(0x4CD4A0, 0xF4240)`（+1,000,000 分，`0x40AE94`）。
  战斗中状态 0xE..0x10 另操作 bit5(0x20)/bit4(0x10)（`0x40AC7B`/`0x40AC95`）。
- 页8/9/10 共用进场 `0x453050`：清 7 队列 → 按页号装链 `0x5A(61 Edg1)` / `0x5C(62 Edg2)` /
  `0x62(76 ExtrEnding)` → 清 `0x56CC84` → 页9 额外提升解锁档（§7）。
- 页8/9/10 finish `0x4535A0`：`0x10000` → `[0x56CCB5]?页5:页3`（非回放分支另写选机字段3）。

## 7. 进度/解锁字段（`0x4AB5B0`）

| 字段 | 含义 | 写点 | 读点 |
|---|---|---|---|
| `0xF00000`(bits20..23) | 最高到达流序 1..8 | `0x4600F0` 对流 {46..52,60} 单调取大（`0x46017D/0x460191`） | 页12 选关机范围 |
| `0x70000`(bits16..18) | 附加解锁档 0..4 | 页9 进场：无继续→≥1（`0x45318E`）、分数>0x1C9C380(3000万)→≥2（`0x4531CD`）、`0x56CCB8` bit14(0x4000)→≥3（`0x453205`）；附加关行为 `0x443FBE`（t>0xE20 且 btn0）→4 | 同上 |
| bit31(`0x80000000`) | 二周目解锁 | `0x4601A2`（流70=0x46 装载时置位） | 页12 选关机周目范围 |

页12 选关机 `0x5F000014`（op04 ctor case18 `0x424D47`，行为 thunk `0x40178F` → **`0x426340`** 九态，
跳表 `0x4267B0`；显示实体 0x5F000015/16/17 由 case19..21 构造）：

- 状态0(`0x426367`)：生成 0x5F000015/16/17 入 0x4AD4FC + `0x61000005` 淡入(-255)；state=8。
- 状态8(`0x426463`)：`0x449E10(this, word[0x4AB5C8], 0xB5)`；`0x61000005`(-16)；timer=0x10；
  state=1；按 `word[0x4AB5C8]` 与 7 比较写 `0x45A750` 矩形到 `[flags+4]`。
- 状态1/3/5(`0x426556`)：等 timer 到 0 → `0x44E470(0x4AB454,320,240)` 指针归中 → state+1。
- 状态2(`0x426585`)：输入。指针横偏 >0x50(80)：`limit = (f7(0x70000)!=0) + fF(0xF00000)`，
  关卡 = 旧值 ± (x≥320 ? 1 : -1)，<0 → limit-1，≥limit → 0；写 word[0x4AB5C8]；state=7。
  纵偏 >0x50：周目 ± (y≥0xA0(160) ? 1 : -1)，上限 = 关卡<8 ? `4+bit31` : `min(f7,4)`，回绕；
  写 word[0x4AB5CA]。居中：btn0 → state=3（`0x61000005`(-16)，timer=0x10）；
  btn1 → state=5（取消路径）。
- 状态4(`0x42678E`)：**`0x45AF30(0x4AB5C0, 0x10000)`** → 页12 finish。

页12 finish `0x453970`：`0x10000` 出口按 `dword[0x4AB5C8]==0x20008` 分页15（鍛錬附加/头像自机），
否则页4。`0x20008` = 关卡8 + 周目2。

## 8. 跨页旗标到页号的完整映射（页4/页12/页8-10）

| 旗标（`0x4AB5C0` 最低位） | 来源 | 去向 |
|---|---|---|
| `0x200000` | 链0耗尽且有继续；链9耗尽且 bit6 清 | 页8（Edg1） |
