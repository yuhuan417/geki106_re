## 2. 逐族修正清单

### 2.1 输入字节语义（影响全部敌我交互）

| 地址 | 旧假设 | 定案 |
|---|---|---|
| `0x4AB596` | 按下沿 | **任意动作键按住**（`0x44E7CF` 三处 DIK 取 OR） |
| `0x4AB597` | 按下沿 | **当前按键码** 0x20..0x2F，未按=0（`0x44E9F6..0x44EA08`） |
| `0x4AB599` | — | 释放（仅输入轮询复制段写入，`0x453F6C`/`0x4513DD`） |

修正后：type-5 狙击（`0x446C50` 族）与 type-8 捕获（`0x447410`）恢复发射；
实测 1400 帧按住开火产生 481 发 `0x10008041`。

### 2.2 2A 族（关7 Boss 四件套）

| 类型 | 行为 | 修正 |

| 0x2A000001 | 0x40A930 | docstring 类型号错位（写成 002） |
| 0x2A000002 | 0x40B040 | 十三态：态1 多出“余数==0xB”门与随机偏移、态3 缺失、态4 扇形错位、态7 条件取反且多发一发 |
| 0x2A000003 | 0x40BB60 | docstring 类型号错位 |
| 0x2A000004 | 0x40C590 | docstring 写成 0x2A000007 |

态 4 双表经**栈跟踪**定案：`A=(64,62,5C,53,47,38,26,62)`、`B=(0,14,26,38,47,53,5C,14)`，
循环只走 i=0..3、每轮两发；态 10 的 7 组向量 `(0xC,-5)(5,0)(0xC,5)(5,5)(5,0xC)(0,5)(-5,0xC)`
及镜像规则经双向实测确认。

### 2.7 自机武器

- **type-5 狙击**：`0x446C50` 族以 `byte[0x4AB597]` 为门 → 改用键码后恢复；
- **type-8 捕获**：`0x447410` 的 `[+0x20]/[+0x24]` 冻结机制；
- **捕获弹 0x10008431**：补 ctor `0x42DA2B`（行为 `0x42F570`、半径 0x18、`[+0x1C]`=pod、
  8.8 位置、速度 0x1400）；行为在屏时生成尾迹、出屏/HP0/pod 亡时**清 pod[+0x28] 解锁下一发**。

### 2.8 碰撞与接触

- 三组碰撞（`0x43BFD0`/`0x43C060`/`0x43C0F0`）判定改为“**内层实体半径 vs 外层坐标**”，
  外层 `[+0x10]` 门按各自操作数位置补；
- `0x45EFF0(type,killer,x,y)` 参数序修正（3 处调用）；
- `0x43C170` 三分支复核：`0x0B000001` 只清 HP；
- 弹体入队去重（`0x43B070`/`0x43B360`）、`0x43AE60` 帧比较改 dword；
- 自机接触整链实测：`0x43C170` t==1 → `0x460C00` → 命数 6→5、`4AD4CC` +5。

### 2.9 VM 脚本

- `0x4603AD` 压栈序确认为 `0x430400(&out, rec[1..4])` ⇒ 记录即 `(x,y,type,prm)`；
- `0x29` 07..0B 的 `x==0` 走标量支（`0x41C1B9`，`prm>>8` → `[+0x1C]`），矛盾消解；
- 26 条链回放无异常，op1..0xD 全覆盖；**op0xE 在 45..76 块中无触发点**。

## 3. 未决与边界（均已写入 ANALYSIS §15/§17）

1. **视觉/手感实机对照**——机器侧只有金标/审计/长跑/回放四类证据；
2. **Windows 兼容补丁**效果需实机验证；

4. `0x4100000D` 战斗流程不可达（指针型 ctor），保留最小 rect 占位。
