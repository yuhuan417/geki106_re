# 页6（調整）设置页规格与实现状态

页6 的逆向结论以原始 `geki106.exe` 为准；复刻代码位于 `remake/pygame/geki.py`。本文只记录已闭合流程和当前实现边界。

## 页流程

- enter `0x4523C0`：设置 palette 2；装载层11/12/13的资源0/1/2并设色键；选择输入预设1；重置场景；创建 `0x6F00000A` 设置总控和 `0x4F000001` 网格实体；建立计时器。
- step `0x4525E0`：帧门、上屏、输入构建、光标定位、系统键、色带绘制、`0x458F80` 合成和旗标检查。
- finish `0x452660`：停止 MIDI 与计时器，清屏并上屏两次，释放层，再按最低页旗标映射出口：`0x100` 到页0，`0x200/0x10000` 到页3，其它值落尾部分支。

## 交互与显示

- `0x6F00000A` 的行为入口为 `0x444A30`。主交互态是态2；系统键 `0x20..0x2F` 调整显示/输入字段，C/X 进入行操作。
- C/X 行表 `0x44547C` 共18项，亮度、对比度、BGM、操作器、鍛錬开关及保存确认等动作已逐项转写。
- `0x4F000001` 网格由 `0x436A5D` 构造，经 `0x435BF4` 设置显示格；`0x4381B0` 推进反弹动画。
- 设置序列化入口 `0x445062` 读取 `0x4A4080..0x4A40F7` 键位数据并生成七组键名显示。
复刻侧该 blob 目前是会话内镜像（`p4_keyblob`）；GRCD 只持久化
`keys.bits`/`disp_cfg.bits` 与排行表，键位 blob 的落盘路径未定位。
