# 页4 实体类型 `0x23000003`：ctor 与行为逐条定案

本文件只写有地址证据的结论。`0x23000003` 在关卡链 0（关 1-8）里出现 **10 次**。

## 1. 构造（`0x43A7F0` → 0x23 族 `0x4013D9` → `0x40D940`）

`0x40D940` 的跳表是 `0x40DE98`（26 项，`eax = type - 0x23000001`，`cmp eax,0x19`/`ja 0x40DE8E`）。
`0x23000003`（`eax=2`）→ `0x40D9C5`：

```
0x40D9C5  eax = [esp+0x3C]              ; payload
0x40D9C9  [esi+0x40] = 0x401B1D         ; 行为 thunk
0x40D9D1  ecx = [eax+0xC]               ; payload[0xC] = d
0x40D9D4  [esi+0x20] = 0xFFFFFFFC       ; vx = -4
0x40D9DB  [esi+0x1C] = ecx              ; d
0x40D9DE  [esi+0x24] = 0                ; vy = 0
```

公共头由 `0x430450` 先填：`[+4]=payload[0]`（x）、`[+8]=payload[4]`（y）、`[+0x14]=payload[8]`（类型）、
`[+0x34]=1`、`[+0x38]=0x45A0E0([+0x3C])`（显示节点，`0x4020D1` 是 `0x45A0E0` 的 thunk）。

## 2. 行为 `0x401B1D` → **`0x40E230`**（整个函数 0x40E230..0x40E2DC）

```
eax = [esi+4] - 0xF0                    ; 0x40E233..0x40E236
if ((unsigned)eax > 0xF2) goto MOVE     ; 0x40E23B..0x40E240 ⇒ x<0xF0 或 x>0x1E2 时跳过
case = byte[0x40E2F0 + (x-0xF0)]        ; 0x40E244 字节表 243 项
       → jmp [case*4 + 0x40E2E0]        ; 0x40E24A 四项目标

  0x40E251 (case 2)：[esi+0x20] = -1；[esi+0x24] = (y <= 0xF0) ? +2 : -2
        （0x40E254..0x40E26D：setle/dec/and 0xFFFFFFFC/add 2）
  0x40E272 (case 1)：[esi+0x20] = -3；[esi+0x24] = 0
  0x40E282 (case 0)：if ([esi+0x1C] != 0) 0x40213F(esi, 0)     ; → 0x43B070
  0x40E292 (case 3 = 默认)：什么都不做

MOVE:                                    ; 0x40E292
  [esi+4] += [esi+0x20]                 ; x += vx
  [esi+8] += [esi+0x24]                 ; y += vy
  (eax,edx) = 0x45A690(x-0x18, y-0x18)  ; 0x401753 thunk → 0x45A690 = 纯传递（mov eax,[esp+4]; mov edx,[esp+8]; ret）
  node = [esi+0x38]
  [node+0x14] = eax                     ; 显示节点 dst.x
  [node+0x18] = edx                     ; 显示节点 dst.y
  if ([esi+0x18] != 0 && [esi+4] > -0x18) return 1   ; 存活
  return 0                              ; 0x40E2D9 → 行为遍置 [+0x34]=0 并隐藏显示节点
```

### 2.1 字节表 `0x40E2F0` 的区间（x 值 → case）

| x 区间 | case | 动作 |
|---|---|---|
| 240 (0xF0) | 0 | `[+0x1C]!=0` 时调 `0x43B070(ent,0)` |
| 360 (0x168) | 1 | vx=-3、vy=0 |
| 482 (0x1E2) | 2 | vx=-1、vy=(y<=0xF0?+2:-2) |
| 其它 | 3 | 无 |

⇒ 实体从右侧（x≈482）以 **vx=-4** 向左移；到 482 改成慢速斜移（-1/±2）；到 360 改成 -3；
到 240 触发 `0x43B070`。x 降到 -0x18 以下且 `[+0x18]==0` 时死亡。

## 3. 语义（有证据的部分）

* `[+0x20]`/`[+0x24]` = 每帧速度（唯一自增点 `0x40E292`，只被三处 case 改）。
* `[+0x18]` 是"存活开关"（`0x40E2C5 test eax,eax; je → return 0`）。
* 显示节点 `[+0x38]` 的 dst 直接由实体坐标 `(x-0x18, y-0x18)` 写入（`0x45A690` 是恒等函数，
  **不是**坐标变换——这一点与本目录里"0x45A690 = 坐标变换"的旧说法相反，旧说法无地址依据）。

## 4. `0x40213F` → `0x43B070`：往 **0x4AD49C 队列**里生成一个实体

```
0x43B07F  dx = [0x56CC8C] - [ent+4]      ; 屏幕参照点 - 实体坐标
0x43B08B  dy = [0x56CC90] - [ent+8]
0x43B093  0x401FB4(arg) → ebx ; sar ebx,4     ; 速度缩放
0x43B0A0  0x40231F(dx, dy) → 角度（ecx）
0x43B0A7  vx = (角度*dy) * ebx >> 8 ; vy = (角度*dx) * ebx >> 8   ; [esp+0x10]/[esp+0x14]
0x43B0C6  两者都为 0 → 直接返回（不生成）
0x43B0D3  0x40113B(ent, &vec)                ; 取一个索引/参数
0x43B0E6  0x4023C4(&local, y, x) → 20 字节记录（rep movsd 5）
0x43B105  0x401861(0x4AD49C, &rec)           ; = 0x435440，队列 0x4AD49C 的入队原语
```

⇒ **payload[0xC]!=0 的这 5 个 `0x23000003` 会一边左移一边朝屏幕参照点打东西**；
payload[0xC]==0 的另外 5 个不会。实跑验证：链 0 的这 10 个实体 `d ∈ {0,1}`，各占一半。
