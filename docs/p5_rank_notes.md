# 页5（記録/排行）规格与实现状态

依据：re_dis 直解；页5 = enter 0x452730 / step 0x452890 / finish 0x452910。

## 页5 enter 0x452730（全序列，逐条）

1. `0x45AFC0(0x4AB5B8, 0x1FC0000)`（亮度 7 位字段）→ `eax*4 - 0xC8` →
   `0x44CDF0(0x4AA7B0, 2, 该值, …)`（thunk 0x4010C3）＝装调色板 2 **带亮度参**。
   失败（al==0）→ `0x45AF30(0x4AB5C0, 2)` 置旗标 2。
2. 同样用 `0x45AFC0(0x4AB5B8, 0xFE000000)`（对比度字段）→ `*4-0xC8` → 再装调色板 2。
3. `0x44E620(0x4AB454, 2, 0x140, 0, 0)`（thunk 0x4019B0）：输入预设 2、基点 (0x140, 0)。
4. `0x44EDA0(0x4AB454, 0)`（thunk 0x401113）。
5. `0x450140(0x4AB4B0, 1, 0x24)`（thunk 0x40127B）：SE 槽1 装资源 0x24（36，菜单旋律）。
   失败 → 旗标 8。
6. `0x458D60(this, 0,0,0,0)`（thunk 0x401262）＝场景重置。
7. 生成 **0x6F000003** @(0,0) prm=-1 入 **0x4AD52C**（0x445AA0，thunk 0x40201D）——排行榜总控。
8. `byte[0x56CCD8] = 0`（0=运行期排行榜 0x4AB5CC 模式）。
9. `0x45A490(0x4AB570, 0)`（thunk 0x401CA3）＝SetPeriod(0)。失败 → 旗标 0x40。
10. `0x45AFF0(0x4AB5C0, 0)`（thunk 0x40208B）返回旗标空。

## 0x45C740（0x402518）——排行榜第 i 项读取（已定案）

- `obj+4` = 关卡字节 s8、`obj+5` = 模式字节；idx = obj[4] + i*2（每关 2 项）。

- 项内布局（0x54B）：+0x00 dword 得分（0x45C7D0 插入排序比较键）、+0x04 word、+0x06 word、
  +0x08 word、+0x0F byte、+0x10 byte、+0x1C..+0x28 dword 组、+0x30 dword（年 = 值+0x76C=1900）、+0x34 dword。
- 0x43E410 态尾逐项读 &local(0xB4) 后用的偏移全部 ≤0x54（此前笔记里的 0xB8/0xBC 等是绝对 esp）：
