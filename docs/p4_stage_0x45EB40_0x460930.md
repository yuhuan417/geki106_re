# 页4「阶段参数装配」两函数逐地址规格：`0x45EB40` / `0x460930`

> 分析对象：`../geki106/geki106.exe`（ImageBase 见 PE 头，PE32）
> 方法：`pefile` 取内存映射 + `capstone` 反汇编（`detail=True`），跨函数调用经 `jmp` thunk 归约到真实实现；esp 增量按每个被调函数真实 `ret N` 累加（`0x45D160`=`ret 4`、`0x45B0A0`=`ret 8`、`0x45B0E0`=`ret 8`、`0x45AFC0`=`ret 4`、`0x458D60`=`ret 0x10`）。
> 本文所有结论均带地址；未证实的条目集中列在 §5，标注「未解」，不作推测性补全。

## 摘要

`0x45EB40`（长 `0x2B0`，`0x4CD4A0` 的方法，经 `0x458D60` 在 `0x458DC9` 调用，签名 `(this,a1,a2)`，`ret 8`）与 `0x460930`（长 `0x110`，`0x4CD590` 的方法，在 `0x458DDD` 调用，`ret 8`）都是**对象构造/重置**函数：不绑层、不载调色板、不载背景资源，只把两个 HUD 全局对象（`0x4CD4A0` 长 `0xF0`、`0x4CD590` 长 `0x48`）的数值字段归零/置初值，并用 `0x45A070`/`0x45A0E0`/`0x45A750` 重建显示表。`0x45EB40` 建 22 个节点（20 数字槽 + 2 图标槽），并写排行榜参照与资源 #78 副本；`0x460930` 建 2 个节点，几何取 `0x4AB5B0` 的 `0xC000` 位段。页4 真正的上屏在同帧的 `0x45EED0`/`0x460A90`，背景与自机来自 VM 命令 11（`0x460600`）与 `0x458E70`。

## 5. 附注：勘误、与任务书不一致处、未解

1. **裁剪矩形未解**：`0x45A170` 的裁剪矩形取自定义表容器 `+0x04..+0x10`（对象 A 在 `0x4CD4A0+0x68..0x74`，对象 B 在 `0x4CD590+0x08..0x14`）。全 `.text` 扫描（`mov [reg+0x68/0x6C/0x70/0x74]` 全枚举、`+0x4/+0x8/+0xC/+0x10` 四连写枚举、`mov …,0x280/0x1E0` 常量写枚举）**均未找到**该 4 字矩形的初始化点；两对象在 BSS 中初始为 0，若为 0 则 `0x45A170` 会把所有节点裁成空。故 HUD 实际裁剪值来源**待查**（可能由页4 之外的层/视口代码写入），实现时需注入一个实测/等价裁剪（如 `(0,0,640,480)`），并回填本节。
2. **勘误（对 ANALYSIS §16.42 的修正）**：`[0x4CD4A0+0xE8]` 不是「`0x4E`=78 字节堆对象」。`0x45ED92` `push 0x4E` 调 `0x45DDE0` 得**长度**、`0x45EDAE` `push 0x4E` 调 `0x45DDA0` 得**基址**，`0x45EDC4`–`0x45EDD3` 按该长度整块 `rep movsd/movsb`；`0x4E` 是 `resource.rom` 的**记录号 78**，其静态长度 3120=`0xC30`（记录 `+0x00` 自带长度）。即 `+0xE8` = 3120 字节场景记录副本。
3. **勘误（参数块偏移基准）**：见 §1 末段。任务书的 `+0x0E/+0x0C/+0x12/+0x11` 与实测 `+0x16/+0x14/+0x1A/+0x19` 是同 4 个字段，仅基准相差 8 字节；自检锚点：App 指针 `P+0xD4`（`0x4505C1` 写 / `0x450A34` 读）。
4. **`0x45D160` 的真实语义**：`0x45D160(0x4CD5D8, 参数块)` 不是"回放管理器更新"，而是**回放头填充**：`rep movsd` `ecx=0xB`(11 dword = `0x2C` 字节) 从参数块拷到 `0x4CD5D8+4`，随后写 `[+4]=0x44505247`("GRPD")、`[+8]=0x41363031`("106A")，`ret 4`。
5. **`0x4AB5B0` 的写回是幂等的**：`0x450A3D`/`0x450A4E`/`0x450A74` 把块内 `+0x1C`/`+0x1D`/`+0x1B`（即开头 `0x450611`/`0x450621`/`0x450634` 从 `0x4AB5B0` 位 1/位 2/位 `0x200` 读出的字节）写回同名字段；`0x450A5F` 把 `+0x18`（`0xC000` 位段）写回位 14–15。无其它写者插入，故为恒等回写。
6. **未解（对象 B 节点 2 的源矩形）**：`0x460930` 只给节点 1 写源矩形，节点 2（`+0x2C`）的 `+0x04..+0x10` 在首次构造时为 `operator new` 未初始化内容；`0x460A90` 也只改节点 2 的源矩形（`0x460AC5` 起写入 `[+0x2C]`），因此首帧前节点 2 的矩形未定义。复刻时应在 `0x460930` 之后、首帧绘制前按 `0x460A90` 的公式预热一次。
7. **未解（`0x4CD590+0x34/+0x38/+0x3C/+0x44`）**：本函数置 0 / 存 a2，但在整段类区间内未找到读取点；用途待定。
8. **未解（数字槽与哨兵节点的重叠）**：循环写槽 `i=0` 得到的是 `0x45A070` 建的头哨兵节点（`0x45A0E0` 返回旧尾），而 `0x45E25D` 从槽 0 起激活、`0x45E020` 从槽 1（`+0x8C`）起写源矩形，导致"显示位数 `n` 与首个有效数字槽"存在 1 槽错位；实现页4 HUD 时须逐帧比对（`0x45E020` 的 `+0x8C` 起始 vs `0x45E25D` 的 `+0x88` 起始）。
