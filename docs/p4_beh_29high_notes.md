# 0x29 族高段行为读码笔记（2026-11-11，未实现→实现中）

依据：`re_dis.py` 递归反汇编 + `esp_flow.py` 栈帧跟踪（帧 = 函数入口 esp）。

## 公共约定

- 实体字段：+4/+8=x/y，+0x14=type，+0x18=HP，+0x1C..+0x30=逐类型状态，+0x34=存活，+0x38=节点。
- `0x45A690(a,b)`（thunk 0x401753）= 恒等返回 (eax=a, edx=b)。
- `0x45A750(out,a,b,c,d)`（thunk 0x40238D）= out[0..3] = {a,b,c,d}（caller 清栈 ret）。
- `0x430400(dst,a,b,c,d)`（thunk 0x4023C4）= rec = {a,b,c,d,栈残留}；`0x43BDC0(queue,rec)`（thunk 0x401FA5，**ret 4**）入队：
  先 `0x430820(rec)` 写 rec[4]=queue+4，再 `0x43A7F0(ent,rec)` 构造（0x430450：ent+4=p0、+8=p1、+0x14=p2、+0x3C=p4）。
- `0x462D71(a,b)`：edx=a%b、eax=a/b。
- `0x40159B→0x45ABB0=cos(0.1°单位)、0x401A50→0x45AAF0=sin`；表值 ±256。
- `0x41FFF0(this, tx, ty, spd)`（thunk 0x401D34，ret 0xC）：以 (tx-this.x, ty-this.y) 方向、
  速度 = `p4_43af90(this,spd)>>4`，从 (this.x, this.y) 发 **0x29000021** 弹（param=&{vx,vy}）。
  spd<0 → 43af90 返回 life-spd（不掷骰）；vx=vy=0 则不发。
- **0x29000021 ctor（0x41CB69）**：beh=0x40166D→0x422D40（已实现）；+0x1C=*p3、+0x20=*(p3+4)、
  +0x24=p0<<8、+0x28=p1<<8、+0x2C=0、+0x18=|*p3|+|*(p3+4)|；SE(槽2, pan=(x-0x140)<<4)。
- **0x4AB5B0 難度 `0x45AFC0(0x4AB5B0,0xC000)==3` → 0x43AF90 内 arg 翻倍**（已在 p4_43af90）。
