# 页4 帧驱动函数精确定案：`0x4593C2` / `0x451110` / `0x451630` / `0x451C50`

## 0. 总述

页 4/11 共用 handler `0x4593C2`（页机 `0x459360`，跳表 `0x4595E4`）：`0x4505B0` 进场 →
`while (0x451110())` 逐帧 → `0x451C50` 收尾 → `0x4595BF` 重分发。`0x451110` 次序：快进判定 →
帧门泵 → 调试文字 → present → VM 一步 → 输入/回放 → 光标+键码 → 帧号+色带 → 三组碰撞 →
`0x458E70` → present → `0x451630`。返回值 = 离页旗标是否为空。

> 说明：本文件只写规格（地址 + 语义 + 数据布局），不含实现代码。所有十进制写在十六进制后的括号里。

---

## 1. 页 handler `0x4593C2`：完整控制流

### 1.1 进入路径（页机）

| 地址 | 指令/动作 | 说明 |
|---|---|---|
| `0x459360` | `push esi; esi = ecx` | `App` 指针入 `esi` |
| `0x459363` | `eax = [esi+0x2BC]` | `App` 的页号字段（`+0x2BC`） |
| `0x459369` | `test eax,eax; je 0x4595CD` | 页号 0 → 退出程序（`PostMessageA(hwnd,0x10,0,0)`，`0x10` = WM_CLOSE） |
| `0x459371` | `push 1; 0x45AFF0(0x4AB5B0,1)` → `push eax` | 计算 `test_not(bit1)`，留作下一调用的第 2 实参 |
| `0x45937E` | `push 2; 0x45AFF0(0x4AB5B0,2)` → `push eax` | 计算 `test_not(bit2)`，成为第 1 实参 |
| `0x45938B` | `0x45C710(0x4AB5CC, test_not(bit2), test_not(bit1))` | 回放缓冲对象按两位状态初始化 |
| `0x459395` | `0x45AF10(0x4AB5C0, 0)` | **清空离页旗标对象**（每次分发必做） |
| `0x4593A1` | `eax = [esi+0x2BC]; dec eax; cmp eax,0xFE; ja 0x4595BF` | 页号-1 > `0xFE`(254) → 落默认分支 |
| `0x4593B3` | `cl = byte[0x459618 + (页号-1)]; jmp [0x4595E4 + cl*4]` | 字节表 → 跳表；**页 4 与页 11 均得下标 3** |

跳表 13 项（`0x4595E4`，下标 0..12）：`0x4593EF`、`0x45941C`、`0x459449`、**`0x4593C2`**、
`0x459476`、`0x4594A3`、`0x4594FD`、`0x459554`、`0x4594D0`、`0x45957E`、`0x45952A`、
`0x4595A8`（不可达）、`0x4595BF`。

### 1.2 `0x4593C2` 本体逐条（全部 5 条 `test/je` 都列在此）

| 地址 | 指令 | 目标 | 语义 |
|---|---|---|---|
| `0x4593C2` | `mov ecx,esi` | — | `this = App` |
| `0x4593C4` | `call 0x401050` → `0x4505B0` | — | 阶段进场（重、每阶段一次），返回 `al` |
| `0x4593C9` | `test al,al` | — | 进场是否成功 |
| `0x4593CB` | `je 0x4593E3` | → 收尾 | **进场返回 0 则一帧都不跑，直接 `0x451C50`** |
| `0x4593CD` | `mov ecx,esi` | — | |
| `0x4593CF` | `call 0x40184D` → `0x451110` | — | 第 1 帧 |
| `0x4593D4` | `test al,al` | — | 1 = 继续 |
| `0x4593D6` | `je 0x4593E3` | → 收尾 | 第 1 帧即返回 0 → 不进循环 |
| `0x4593D8` | `mov ecx,esi` | — | ↑ 循环体起点 |
| `0x4593DA` | `call 0x40184D` → `0x451110` | — | 下一帧 |
| `0x4593DF` | `test al,al` | — | |
| `0x4593E1` | `jne 0x4593D8` | ↑ | **返回 1 就继续循环**；返回 0 落到收尾 |
| `0x4593E3` | `mov ecx,esi` | — | |
| `0x4593E5` | `call 0x401807` → `0x451C50` | — | 收尾：**无论进场成功、还是循环跑过多少帧，都会执行** |
| `0x4593EA` | `jmp 0x4595BF` | — | 回页机 |

while 语义精确定义：`if (进) { do { 帧 } while (帧返回 1); }` —— 等价于
`if (进) while (0x451110()) {}`，**首帧无条件执行，且每帧之间无额外等待**（帧率由
`0x451110` 内的 `0x458B80` 帧门负责）。

### 1.3 `0x4505B0` 门（进场，返回真才开局）

只列与页 4 分支有关的定案（细节另文）：

- `0x4505C8`：`cmp [App+0x2BC],0xB`（页 11 = 回放）。**相等** → `0x45D1A0(0x4CD5D8, &块)`
  从回放头读回 11 个 dword 到栈块，随即 `jmp 0x450A3D`（跳过全部常规初始化）。
  **不等** → 继续常规进场。
- 常规进场：按 `[0x4AB5C8]`（关）、`[0x4AB5CA]`（周目）与状态字建 0xD8(216) 字节参数块 →
  `0x45D160(0x4CD5D8, &块)` 写入回放头（`0x45D160` 在 `+4` 处写 `0xB`(11) 个 dword 并盖
  magic `'GRPD'`=`0x44505247`、`'106A'`=`0x41363031`）。
- `0x450A3D`..`0x450A7E`：把参数块的 4 个字段写回状态位域
  `0x4AB5B0`：bit1（`0x45B0A0(…,1,v)` @`0x450A44`）、bit2（`@0x450A52`）、
  `0x45B0E0(…,0xC000,v)` @`0x450A6A`、bit `0x200`（`0x45B0A0(…,0x200,v)` @`0x450A7E`）。
  页 11 时这 4 个值来自回放头，即**回放恢复游戏配置**。
- `0x450AA1`：`0x458D60(App,…)` 一次（队列净化 + 子系统 tick）。
- `0x450AC9`..`0x450AF6`：清统计/输入区：`[0x56CC94]`、`[0x56CC98]`、`[0x56CC9C]`、
  `[0x56CCA0]`、`[0x56CCA4]`、`[0x56CCA8]`（帧号）、`[0x56CCAC]`（泵计数）、
  `[0x56CCB0]`（word）、`[0x56CCB2]`、`[0x56CCB3]` 全 0。
- `0x450AE7`：`[0x56CCB4] = 0`（进场帧循环门，见 §3）。
- `0x450AFA`：`[0x56CCB5] = (页号 == 0xB)`（回放页标志）。
- `0x450B05`：`0x45AF10(0x56CCB8,0)`（输入/系统状态字清零）。
- `0x450B68`：`0x44CDF0(0x4AA7B0, 1, f(状态字 0xFE000000), f(状态字 0x1FC0000), 0xFFFFFF01)`；
  RT_STRING id 1 = `bmcm\bm_pal.bmp`（亮调色板），第 4 参 `0xFFFFFF01`(=-255) = 从全黑淡入。
  失败 → `0x45AF30(0x4AB5C0,2)`。
- `0x450D98`：`[App+0x2C4] = 1`（快进倍率初值 → 见 §2.3，正常游戏 N=1）。
- `0x450DA8`：`0x45A490(0x4AB570, 0)` = `SetPeriod(0)` → 周期取默认 `0x3C`(60) Hz。
- `0x450DB7`：**返回 `0x45AFF0(0x4AB5C0,0)`**（离页旗标为空 = 真）。

`f(x)` = `(x & mask) 的字段值 * 4 - 0xC8(200)`：`0x45AFC0(0x4AB5B8, 0x1FC0000)` 送第 3 实参
（亮度），`0x45AFC0(0x4AB5B8, 0xFE000000)` 送第 2 实参（对比）。页 4 恒成立：
`0x45AFC0` 返回 0 时两值都是 `-200`。

### 1.4 页机尾部 `0x4595BF`

`0x4595BF`：`eax = [esi+0x2BC]; test; jne 0x459371` —— 页号非 0 就**回跳 `0x459371` 重新分发**
（不经过 `0x459363` 的页 0 检查，也不重新 push esi）。页号为 0 →
`0x4595CD` `edx=[esi+0x1C]`(hwnd) → `0x4595D0..0x4595D7` `PostMessageA(hwnd, 0x10(16), 0, 0)` →
`0x4595DD` 返回 0。即"页号置 0"是唯一的退出程序手段。

## 2. `0x451110`：有序步骤表

### 2.0 栈帧

`0x451110` SEH 保护（`0x451116` push -1、`0x451118` push `0x495098`、`0x45111D` push 旧
`fs:[0]`）→ `0x451125 sub esp,0x50`(80) → `0x451128 push ebx`。`ebx` = `App`。
记返回地址为 `R`，则 `0x451325` 之后 `esp = R-0x60(96)`，局部区 `R-0x5C`..`R-0xC`。
关键局部：

| 位置 | 大小 | 用途 |
|---|---|---|
| `[esp+7]`（`R-0x59`） | byte | **present/色带使能**：正常路径 `0x451161` 置 1；快进跳过路径 `0x45114C` 置 0 |
| `[esp+0x1C]`（`R-0x44`） | 0x18(24) | 回放帧缓冲（`0x45D2B0` 的输出，随后 6 字节覆盖到 `0x4AB594`） |
| `[esp+8]`→`R-0x58` | 0x58(88) | 碰撞上下文对象（`0x43BF60` 只写 vtable `0x498754`；`+0x54` 在 `0x451478` 清零） |
| `[esp+0x18]` / `[esp+0x40]` | 0x28 / — | 进度文字用 sprintf 临时串 / 累加串 |

### 2.2 快进分支（`App[0x2C4]`）

- `[App+0x2C4]`（`0x2C4`=708）= 快进倍率。零值 = 快进关闭（此时 S2 不执行）。
- `0x451135`：`push eax([App+0x2C4])`，`0x451136`：`push [0x56CCA8]`（帧号），
  `0x45113C`：`0x462D71(帧号, 倍率)` → `eax`=商、`edx`=余数。
- `0x451144`：`[esp+0xC] = eax`（商写入一个**不再被读的**局部，实测全函数无读者）。
- `0x451148`：`test edx,edx`；`0x45114A`：`je 0x451156` ⇒ **`帧号 % 倍率 == 0` 才是"推进帧"**，
  否则该帧被整帧跳过：`0x45114C` `[esp+7]=0`、`0x451151` `jmp 0x451325`。
- 跳过时**不做**：泵门（S3/S4）、present（S7）、色带（S16）、`0x458EF0`（S22）。
  **仍做**：VM 一步、输入/回放、光标归位、键码分发、帧号 +1、三组碰撞、`0x458E70`、进场循环、返回值。

### 2.3 泵次数公式

```
0x451156  eax = [App+0x2C4]
0x45115D  neg eax / 0x45115F sbb eax,eax        ; [0x2C4]!=0 → -1，否则 0
0x451166  and al,0xFD                           ; -1 → 0xFFFFFFFD，0 → 0
0x451168  add eax,4                             ; 0xFFFFFFFD+4 回绕 = 1，0+4 = 4
0x45116B  je 0x451186                           ; 结果恒非 0 ⇒ 死代码
0x45116D  esi = eax
0x45116F  do { 0x458B80(App); [0x56CCAC]++ } while (--esi)
```

⇒ `N = ([App+0x2C4] == 0) ? 4 : 1`。页 4 进场 `0x450D98` 把 `[App+0x2C4]` 置 1，
所以**页 4 常态每帧只泵 1 次**；只有被外部清零（如回放里按 btn1，`0x45139F`）时才 4 次。
`0x458B80` 本身 = PeekMessage 泵 + 60 Hz 帧门（另文），其中 `App[0x2C0]`（`0x2C0`=704）：
`==2` → `0x458D30`；`!=0` → `Sleep(0x32)`(50ms) + 重泵；`==0` → 帧门返回 2 则直接返回、
返回 1 则忙等、返回 0 则 `Sleep(1)` + 重泵。

### 2.4 `0x458CB0` / `0x450FE0`

- `0x458CB0`（S7）：`GetClientRect(App[0x1C])` + `ClientToScreen` →
  `0x44D740(0x4AA7B0, right+left-2, bottom+top-2)`。窗口 640×480 时实参为
  `(0x27E(638), 0x1DE(478))`。**这是本帧唯一的上屏动作**（`0x44D740` 内部按帧号奇偶处理
  调色板淡入淡出）。
- `0x450FE0`（S8，返回值**被丢弃**）：`0x460350(0x56CC4C)` 为 0 → 本帧不推进，直接返回。
  否则按 `0x45B030(0x4AB5B0,1)`（bit0 是否清）分两支：
  - bit0 **清** → `cmd = (s16)0x460800(0x56CC4C)`：
    - `cmd == 0` → `0x460EE0(0x4CD590)`（取 `[0x4CD590+0x40]`，序列/回调指针）非 0：
      `0x45F760(0x4CD4A0)`（`0x45105E`）→ `0x45AF30(0x4AB5C0, 0x200000)`（`0x451068`）；
      为 0：`0x4602D0(0x56CC4C, 9)`（把 VM 命令改成 9，`0x451078`）+
      `0x45AF10(0x56CC84, 0)`（清输入位，`0x451084`）。
    - `cmd == 9` → `0x45F760(0x4CD4A0)`（`0x451020`）→
      `0x45AF30(0x4AB5C0, 0x45AFF0(0x56CCB8,0x40) ? 0x400000 : 0x200000)`（`0x45102C`..`0x45104C`）。
  - bit0 **置** → `cmd == 0x2E(46)` → `0x45AF30(0x4AB5C0, 0x400000)`（`0x4510A6`）；
    `cmd == 0x58(88)` → `0x45AF30(0x4AB5C0, 0x800000)`（`0x4510BD`）。
  ⇒ `0x200000`/`0x400000`/`0x800000` 三个"跨页信号"全部由 `0x450FE0` 内的 VM 命令产生，
  与 `0x451110` 的返回值无关（`0x451110` 只看旗标对象是否为空）。

### 2.5 输入记录 / 回放（S9 / S10）

`0x4AB594` 起 0x18(24) 字节 = 帧输入记录（`0x4AB454` = DirectInput 管理器）：

| 偏移 | 大小 | 含义 |
|---|---|---|
| `+0` / `+1` | byte×2 | btn0 / btn1 按住 |
| `+2` / `+3` | byte×2 | 按下沿 / 松开沿 |
| `+4` / `+5` | byte×2 | btn2 / btn3 边沿 |
| `+6`（`0x4AB59A`） | byte | 键码 |
| `+8` / `+0xC`（`0x4AB59C`/`0x4AB5A0`） | dword×2 | 指针/自机坐标 x / y |
| `+0x10` / `+0x14` | dword×2 | 增量 dx / dy（由 `0x56CC8C` 处保存的上次坐标算出） |

- 非回放（`0x45132C`..`0x451355`）：`0x44EB60(0x4AB454, 0x56CC8C, 0)` 建记录（第 3 参 0 =
  用真实指针）→ `0x45D1D0(0x4CD5D8, 0x4AB594)` 把该帧压入回放。
