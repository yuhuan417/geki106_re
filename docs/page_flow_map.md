## 4. 结局选择

- 页 8（Edg1，链 0x5A→流 61）：链 0/9 走完且（用过继续 或 最终 boss 未被击破）。
- 页 9（Edg2，链 0x5C→流 62）：链 9 耗尽且 `0x56CCB8` bit6 置位
  （0x2A000001 最终 boss 死亡序列 0x40AE88 置位）。页9 进场提升解锁档
  （0x453154..0x45320C：无继续→≥1、分数>3000 万→≥2、bit14→≥3）。
- 页 10（ExtrEnding，链 0x62→流 76）：鍛錬元祖关（链 0x58）耗尽。
- 二周目：流 70 装载时置 0x4AB5B0 bit31（0x4601A2）→ 页 12 周目+1。

- `0x23000006` 的 `rec[0xC]`（未初始化栈缓冲）→ 传 0。
- `0x4100000D` 战斗不可达 → 占位。
- `0x61000001` 生成的 type0 敌机（堆残留行为）→ 漂移近似（`_p4_type0_drift`）。
