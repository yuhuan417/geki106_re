## 4. 结局选择

- 页 8（Edg1，链 0x5A→流 61）：链 0/9 走完且（用过继续 或 最终 boss 未被击破）。
- 页 9（Edg2，链 0x5C→流 62）：链 9 耗尽且 `0x56CCB8` bit6 置位
  （0x2A000001 最终 boss 死亡序列 0x40AE88 置位）。页9 进场提升解锁档
  （0x453154..0x45320C：无继续→≥1、分数>3000 万→≥2、bit14→≥3）。
