**勘误记录**：`p4_block()` 普通局此前写 `esi*4+0xB`（链 11＝单关回菜单）——
0x450651..0x450681 普通路径**不写块 +0x10**（rep stosd 清零后保持 0）⇒ 链 0。
si/bp 三分支（0x450686 起）只在鍛錬路径可达。分析文档旧"新游戏走链 0"结论正确，
2026-11-14 的"勘误"本身有误，已回退。

## 6. 复查后的缺漏（按优先级）

1. **0x4F000002 / 0x6F000004（流 61 开场的擦切/字形控制）**：页 8/9/10 中走
   通用 spawn 落 default 行为（无 ctor 落地）。视觉影响：结局开场可能少一层
   擦入/字形效果。待逐条读 0x4355E0/0x448FF0 的对应 case。
2. **45EFF0 的 sel 分支全面性**：sel 现按 arg2（击杀者类型）& 0xF00——本次只
   论证了 0x400（捕获）与 readme 吻合；0x100/0x200/0x500 的连击/波纹/赏字链
   （0x45E4A0 数字板、0x32000004/05）逻辑已在复刻中，但**触发频率依赖击杀者
   类型分布**，建议实机对照弹字出现频率。
3. **0x45FAD0 的"可捕获"字段**：= 表项高 16 位（已逐字节核对，非 UB）。
   第一关 18 种可捕；各关表已 dump（0x4993CC..0x499678）。
4. **页 10 的 0x45EED0/0x460A90**：HUD 链与命数字形在页10 收尾的调用已接线，
   0x460A90 未逐字节落地（记日志）。
5. **页 15（0x454950）**：鍛錬附加关的进场已实现，但 0x6B000001 舞台总控的
   行为链（0x443606）仅部分——附加关实机内容未对照。
6. **实机对照**：本会话所有验证均为无头 harness；键盘/鼠标手感和结局画面
   仍需用户实机确认。
