# 0x31 弹体族全量对账（0x31000001..0x3100001F，26 型 + 0x31000010 补漏）

日期：2026-11-20。方法：`re_dis` 递归下降反汇编 0x4308A0..0x433B60（ctor 全跳表）与
0x43AF90..0x43B6C0（发弹辅助全 9 个），逐指令对 `remake/pygame/page4.py`（beh + 发弹辅助）
与 `remake/pygame/geki.py`（spawn 的 0x31 ctor 分支 + P31_CTOR 表）。

## 0. 结构事实（本轮新钉死）

- **ctor 派发**：0x435440（0x401861）在**入队时**分配 0x48 字节并立即调 0x4308A0
  （0x401514）。0x4308A0 先跑基类 0x430450（[+4]=x、[+8]=y、[+0x14]=type、byte[0x34]=1、
  [+0x38]=节点 0x45A0E0、[+0x3C]=rec[4]=栈垃圾），再按 type 查表：
  - 0x31：`jmp [eax*4+0x431B30]`，idx=(type−0x31000001)，**31 项**（0x31000001..1F 全有，
    1F→0x431653）；0x31000002/07/0B/1A→默认 0x431B12（只跑基类，无 beh）。
  - 0x32000001 专案 0x431726；0x32000002..10 → `jmp [eax*4+0x431BAC]`（15 项）。
- **rec 布局**：0x430400(rec, x, y, type, prm) = `{x, y, type, prm, 栈垃圾}`；
  ctor 用 `mov edx,[edi+0xC]` 取 rec[3]=prm。速度类 ctor 对 prm **解引用**（[prm]=vx、
  [prm+4]=vy，即 0x430400 的第 5 参是 `&vxvy` 指针），标量类直接用值。
- **0x401A0A→0x45A790(out,a,b,c,d)** = rect 四分量加减（out=node+4 → l+=a, t+=b, r+=c, b+=d）。
- **0x401753→0x45A690** = `eax=[esp+4]; edx=[esp+8]; ret`（恒等二元组转发，无变换）。
- **0x4305F0(e,r)**：`x−r>0x27F 或 x+r≤0 或 y−r>0x1DF 或 y+r≤0 → 0，否则 1`（已复核）。
- **三角表**：0x40159B→0x45ABB0=cos、0x401A50→0x45AAF0=sin（page4_cos/page4_sin 对应无误）。
- **0x432390 归属**：无任何直接引用；经 thunk **0x401B7C** 由 0x32 族 ctor 0x431726
  （0x32000001 专案）写进 [+0x40] → **0x432390 是 0x32000001（0x32 大玉）的行为**，
  不是 0x31 型；矩阵未列正确。其体内 `[esi+0x14]==0x32000005` 检查即 0x32 族特征。
  （Python 侧 0x32000001 行为另行处理，不在本审计范围。）
- **0x4335F0** = 0x32000010 的行为（ctor 0x431AA0 → 0x4010E6），非 0x31 型，Python 已有。
- **ctor SE**：各型 ctor 开头普遍 `0x4013A2(0x4AB4B0, se, (x−0x140)<<4)`（0x450350）。

## 2. beh 对账（26 个 + 0x432390 归属）

零差异：`_beh_4321C0`、`_beh_432250`、`_beh_432340`、`_beh_4325E0`、`_beh_432820`、
`_beh_4328B0`、`_beh_433390`、`_beh_433480`、`_beh_4324B0`、`_beh_432C80`、`_beh_432DC0`、
`_beh_432FE0`、`_beh_433340`、`_beh_433520`、`_beh_432F20`、`_beh_432C00`、`_beh_4331C0`
（含 0x43321C 跳表 5 项 + 0x433230 字节表 15 项逐项核对）、`_beh_432E30`。

已修（exe 地址 → Python 现值→应值）：

1. **0x43268C/0x4326A9（_beh_432670，0x31000008）**：rect 动画应为 `l/r−=0x20`（t/b 不动），
   且 `l==0x130` 判**更新后**的 l；命中再 `l/r+=0x60、t/b−=0x20`。原实现写成 `t/b−=0x20`
   （l/r 不动）+ 判旧 l + 命中 `l/r+=0x60、t/b−=0x40`——贴图伸缩方向整组颠倒。
2. **0x4327B5/0x4327D2（_beh_4327A0，0x31000009）**：同类——应为 `l/r+=0x20`、判更新后
   `l==0x1B0`、命中 `l/r−=0x60、t/b+=0x20`。
3. **0x432B54（_beh_432990，0x3100000E）**：无父体时的出屏判亡原手写
   `x<−0x10 or x>0x290 or y<−0x10 or y>0x1F0`（漏 x==−0x10/y==−0x10、0x290→0x28F、
   0x1F0→0x1EF），改为 `p4_4305f0(e,0x10)!=1`。
4. **0x4332DC（_beh_433260，0x31000017）**：出屏判亡原
   `x<−0x18 or x>0x298 or y<−0x18 or y>0x1E0`（y 上界 0x1E0 vs 0x1F7 差 0x17，且含两处
   边界差一），改为 `p4_4305f0(e,0x18)==1 and HP`。
5. **0x433060（_beh_433060，0x31000015）**：a) exe **不写 node.dst**（ctor 定格后不动），
   删除 Python 的每帧 dst 更新；b) t≥0x5A 后判亡原手写边界（同 3 类错误，且 r 应为 0xC：
   x≤−0xC/x>0x28B/y≤−0xC/y>0x1EB），改 `p4_4305f0(e,0xC)==1`。
6. **0x433820（_beh_433820，0x3100001D）**：双计数器——`[0x20]=++[0x20]`（相位，ctor 起
   prm&0xFFFF；原实现从不自增，导致 byte[0x20]&0x10 选弹恒为初值）与 `[0x1C]=++[0x1C]`
   （外伸距离+寿命）；spin 改 **cos**(225·(t2&0xF))·min(t2,0x30)（原误用 sin 且 t 用错
   计数器）；补 HP==0 分支结构（0x45AFC0(0x56CCB8,0x10) 门 + [0x2C] 门 + byte[0x20]&0x10
   选 0x5A000004/0x4A000005，队列 4FC/4CC 与原一致）。
7. **0x433AD0（_beh_433AD0，0x3100001F）**：位置推进必须**先于**反弹（用旧速度走完本帧，
   反号只影响下一帧；原实现先反号再推进=反弹帧速度瞬变）；x/y 的 `<0` 判定必须**有符号**
   （原 `& 0xFFFFFFFF` 后比较恒假 → 负向反弹分支死代码）；反弹计数**逐轴** +1（同帧双轴
   反弹 +2；原只 +1）；SE 门 = `计数变化 且 新计数<5`（原 `新计数<5`，双轴反弹时 4→5 的
   那帧会多放一次 SE）。
8. **0x43B500（p4_43B500）**：出射点是**入参 (x0,y0)**（0x43B566/0x43B56B 读
   [esp+0x4C]=arg2/arg1），不是实体 [e+4]/[e+8]；调用点 0x41A7E2 传 (ex−0x10, ey)，
   原实现弹点右偏 0x10。

## 5. 备注

- `0x430450` 基类把 rec[4]（0x430400 第 5 参之外的栈残留）写进 [+0x3C]；0x31 beh 无
  `[esi+0x3C]` 读点，Python 未建模无影响。
- `p4_45aa80` 的 `a²+b²` 32 位回绕为负时 exe 会读表外内存（word[负索引]），Python 按0→1
  处理；实际坐标量级不可达，未改。
- 0x432390（0x32000001 beh）与 0x4335F0（0x32000010 beh）属 0x32 族，本轮只确认归属，
  未逐指令对账（0x4335F0 Python 已有实现）。
