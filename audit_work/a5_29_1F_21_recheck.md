# a5：0x29 族 0x2900001F/20/21 全量审计 + 19..1E 六型复核

日期：2026-11-20。工具：re_dis（递归下降）+ 原始字节扫描 + trace_esp（esp 基准追踪）。
所有结论均给出 exe 地址+指令原文；Python 侧只读 `remake/pygame/page4.py`（工作区版本）。

## 0. 原语 ABI（本次重新钉死，后续审计直接引用）

- `0x4023c4 → 0x430400`（plain ret，5 参 cdecl）：
  `0x430400 sub esp,0x14` 后把 `{arg2,arg3,arg4,arg5,[E1-4]}`（E1=入口 esp）
  5 dword `rep movsd` 拷到 **arg1**（记录输出缓冲），返回 arg1。
  即 **record = {p0块, p1块, type, p3块, [栈残渣]}**。
  第 5 槽是 `sub esp,0x14` 帧的最后一个本地（E1-4，调用方未写、属栈残渣），
  但**在入队前会被 0x430820 覆写**（见下），无实际影响。
- `0x401fa5 → 0x43BDC0`（ret 4，ecx=0x4AD43C 队列对象，栈参=记录指针）：
  1. `0x43BDDE call 0x401352 → 0x430820`：`mov eax,[esp+4]; add ecx,4; mov [eax+0x10],ecx`
     —— **record[4] = 0x4AD440（节点池对象）**。
  2. `0x47C7C0`（operator new 0x5C）分配实体，`0x4016F4 → 0x43A7F0` 构造：
     `0x40180C → 0x430450`：`[ent+0x3C]=record[4](=0x4AD440)`、`rep stosd` 清 +4..+0x38、
     `[ent+0x04]=record[0]`(x)、`[ent+0x08]=record[1]`(y)、`[ent+0x14]=record[2]`(type)、
     `[ent+0x34]=1`、`0x4020D1(ecx=+0x3C) → 0x45A0E0` 分配 0x28 字节节点入池
     （`[ent+0x38]` = 返回的旧池头 = 本实体用的节点；node +0x20/+0x24 为池链）。
     随后按 type 族分派（0x43A82C `cmp eax,0x2F000000…`）→ 0x29 族进 `0x41C040`。
- `0x401753 → 0x45A690`：`mov eax,[esp+4]; mov edx,[esp+8]; ret` —— **恒等 (x,y)→(eax,edx)**。
- `0x40238d → 0x45A750`：`[dest]=arg2, [dest+4]=arg3, [dest+8]=arg4, [dest+0xC]=arg5`
  —— 4 dword 块写入（p0 三参块 + p1 首参、或 1A 的 4 dword quad）。
- `0x462D71`：trunc divmod（`cdq/idiv`；负商修正分支 `0x462D84 jge` 对 x86 余数符号
  恒不可达，死代码）→ eax=商、edx=余，**向零截断**。
- `0x4013A2 → 0x450350`（ecx=0x4AB4B0，栈参 slot,param）：SE 播放；slot==2 时
  `0x45037F..0x450392` 用 `[esi+0x5E]` 翻转在 slot 2/3 间交替；param 夹取 [-0x2710,0x2710]。
- `0x401D34 → 0x41FFF0`（发 0x29000021 弹）；`0x4021E9 → 0x4305F0`（在屏判据）；
  `0x40159B → 0x45ABB0`（cos 表，参数 |a|%0x384 归一，**可为负**）。

## 1. 0x2900001F（ctor 0x41C99E，beh 0x422950）

### 1.1 ctor（0x41C99E..0x41CA66，公共尾 0x41CB2B..0x41CB66）

### 1.2 beh 0x422950 逐指令

## 4. 第二部分：19..1E 六型复核

### ① 0x29000019 死亡判定（0x421FE0）—— **复核通过**
`0x422049 mov eax,[esi+0x2C]`；`0x42204C test eax,eax`（**减前值**）；`0x42204E lea ecx,[eax-1]`；
`0x422051 mov [esi+0x2C],ecx`；`0x422054 je 0x42205D` → `0x42205D xor eax,eax; ret`（=0 死），
否则 `0x422056 mov eax,1`。即 **return v≠0**（v=减前 [0x2C]）✓ Python `_beh_421FE0` 一致。
主死切 beh（0x42201C/0x422026 `[esi+0x40]=0x401852`）、态字变化且 [0x2C]≠0 → [0x2C]=1
（0x422031..0x422042）均与 Python 一致 ✓。

### ② 0x2900001A 死亡判定（0x4220A0）—— **复核通过**
缓动 `0x4220A4..0x4220DC`：d=[0x28]-[0x20]，`test/jl/add 0xF/sar 4`（≥0 时 +0xF 再算术右移4）✓；
尾部 `0x422125 mov eax,[esi+0x30]; 0x422128 test eax,eax; 0x42212A lea ecx,[eax-1];
0x42212D mov [esi+0x30],ecx; 0x422130 je 0x42213A(死)` —— **return v≠0（[0x30]，减前值）** ✓。

### ③ 0x2900001B（0x422170）—— **复核通过**
- m：`0x4221B7 neg al`（al=(主态字>>0xF)&1，0x422196 shr/0x42219B and）→ `0x4221BB sbb eax,eax` →
  `0x4221CA and al,0xFE` → `0x4221D1 add eax,5` → **m = bl?3:5** ✓。
- off：`0x422209 call 0x462D71(0xB4-t, m)` → `0x422213 sub eax,esi(t)` → `0x422219 add eax,0xB5`
